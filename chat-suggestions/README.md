# chat-suggestions/ — стартовые вопросы чата

Кнопки-подсказки в пустом чате сайта. Для страницы в YAML лежит ровно 6 вопросов; сайт показывает 3 случайных из них, выбор делается заново при смене страницы. Страницы без записи получают три фиксированных универсальных вопроса (`web/src/domain/chat-suggestion-pools.ts`).

## Раскладка

| Файл | Что внутри |
| --- | --- |
| `home.yaml` | `questions` — главная страница |
| `<course>.yaml` | `course` — страница курса; `docs` — словарь `id страницы → вопросы` |

Id страницы — имя файла без `.md`: лекция `01_sep03_matrices`, подготовка `kr1`, `exam1`, `colloq1`, `quiz-limits`, а также `theory` и `program`. Файл есть в `notes/<course>/`, `prep/<course>/`, `theory/<course>.md` или `program/<course>.md`.

## Как писать вопросы

- Каждый вопрос в YAML — в двойных кавычках (двоеточие внутри ломает разбор). Ровно 6, все разные, до 110 знаков, от первого лица студента, без TeX (сайт показывает текст как есть; формулы пишите Юникодом: `ε`, `∀`, `≥`).
- Вопрос про то, что есть на странице: понятие, доказательство, типичная ошибка, приём решения, правило курса. Не «объясни тему».
- Разный жанр: объяснить идею, разобрать доказательство, найти ловушку, дать пример или контрпример, потренироваться.
- Лектора и даты в вопрос не вносим: они меняются.

## Сборка

```bash
uv run scripts/build_chat_suggestions.py          # YAML → web/src/domain/chat-suggestions.json
uv run scripts/build_chat_suggestions.py --check  # проверка без записи (CI и тесты)
```

JSON коммитится: сайт собирается без Python.
