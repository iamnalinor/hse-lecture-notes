# О контрольной

КР-2 пишется 10 декабря, на 5–6 парах. Оценка за КР-2 входит в оценку за первый семестр с весом $0{,}2$. КР-2 проверяет лекции 6–13: от подпоследовательностей и критерия Коши через предел и непрерывность функции до производной, исследования функции на монотонность и экстремумы и теорем Ролля, Лагранжа и Коши.

Демоверсии КР-2 пока нет: задачи ниже подобраны по темам 6–13 и лекциям, страница обновится, когда демоверсия выйдет.

Правила:

1. Можно взять с собой листок со своими записями классических пределов и эквивалентностей.
2. КР-2 блокирующая: нужно набрать не меньше $35$ баллов из $100$.
3. Экзамен 21 декабря — для тех, кто не сдал КР-2 или коллоквиум, и для тех, кто хочет улучшить оценку по одному из элементов контроля.

На листок стоит выписать таблицу эквивалентностей при $x \to 0$ вместе с $\arcsin x \sim x$ и $\operatorname{arctg} x \sim x$, следствия второго замечательного предела, формулу $u^v = e^{v \ln u}$, таблицу производных (включая обратные тригонометрические) и формулы для $k$ и $b$ наклонной асимптоты.

# Задачи

## 1. Частичные пределы и критерий Коши {#sec:kr2:partial}

1. Чтобы найти частичные пределы, разбейте номера на конечное число бесконечных частей, на каждой из которых член задан одной формулой: по чётности $n$ при $(-1)^n$, по остатку $n$ от деления на период при $\sin\frac{\pi n}{p}$, $\cos\frac{\pi n}{p}$.
2. Найдите предел на каждой части. По утверждению [-@prop:lec06:split] частичные пределы последовательности ровно эти значения, других нет.
3. Верхний и нижний пределы — наибольший и наименьший из частичных (определение [-@def:lec06:limsup]).
4. Сходимость по критерию Коши (теорема [-@thm:lec06:cauchy]): оцените $|x_{n+p} - x_n|$ сверху выражением, которое зависит только от $n$ и стремится к нулю (телескопическая сумма, геометрическая прогрессия), и укажите $N(\varepsilon)$ явно.
5. Расходимость: отрицание фундаментальности. Найдите $\varepsilon_0 > 0$ и для каждого $N$ номера $m, n > N$ (обычно $m = 2n$) с $|x_m - x_n| \ge \varepsilon_0$. Оценки $|x_{n+1} - x_n| \to 0$ для сходимости мало (замечание [-@rem:lec06:neighbors]).

::: {.problem #prob:kr2:partial-cos}
Найдите множество частичных пределов, верхний и нижний пределы последовательности $x_n = \dfrac{2n - 1}{n + 3} \cos\dfrac{2\pi n}{3}$.
:::

::: solution
Второй множитель зависит только от остатка $n$ при делении на $3$: при $n = 3k$ имеем $\cos 2\pi k = 1$, при $n = 3k + 1$ и $n = 3k + 2$ — $\cos\frac{2\pi}{3} = \cos\frac{4\pi}{3} = -\frac12$. Первый множитель $\frac{2n - 1}{n + 3} = \frac{2 - 1/n}{1 + 3/n} \to 2$. Номера разбиваются на три бесконечные части. На части $n = 3k$ получаем $x_n = \frac{2n - 1}{n + 3} \to 2$, на двух других $x_n = -\frac12 \cdot \frac{2n - 1}{n + 3} \to -1$. По утверждению [-@prop:lec06:split] частичных пределов ровно два: $2$ и $-1$.

*Ответ:* $\{-1,\ 2\}$; $\varlimsup x_n = 2$, $\varliminf x_n = -1$.
:::

::: {.problem #prob:kr2:cauchy-sum}
С помощью критерия Коши докажите, что сходится последовательность $x_n = \displaystyle\sum_{k=1}^{n} \frac{\sin k^2}{k(k + 1)}$.
:::

::: solution
*Ключ:* оценить $|\sin k^2| \le 1$ и свернуть сумму $\frac{1}{k(k + 1)} = \frac1k - \frac{1}{k + 1}$. При любых $n, p \in \N$
$$|x_{n+p} - x_n| = \left|\sum_{k=n+1}^{n+p} \frac{\sin k^2}{k(k + 1)}\right| \le \sum_{k=n+1}^{n+p} \left(\frac1k - \frac{1}{k + 1}\right) = \frac{1}{n + 1} - \frac{1}{n + p + 1} < \frac{1}{n + 1}.$$
Пусть $\varepsilon > 0$ и $N = \left[\frac1\varepsilon\right]$. При $m > n > N$ имеем $n \ge N + 1 > \frac1\varepsilon$, и, взяв $p = m - n$, получаем $|x_m - x_n| < \frac{1}{n + 1} < \frac1n < \varepsilon$. Последовательность фундаментальна (определение [-@def:lec06:fundamental]) и по критерию Коши сходится.
:::

Ещё задачи: [-@prob:lec06:partial-mod], [-@prob:lec06:blocks], [-@prob:lec06:cauchy-converge], [-@prob:lec06:cauchy-diverge], [-@prob:lec06:three-subseq].

## 2. Предел функции по определению {#sec:kr2:definition}

1. По Коши (определение [-@def:lec07:cauchy-limit]): приведите $|f(x) - A|$ к общему знаменателю и выделите множитель $|x - x_0|$.
2. Остальную часть ограничьте, заранее взяв $\delta \le \delta_0$ (обычно $\delta_0 = 1$ или $\frac12$), чтобы знаменатель был отделён от нуля (замечание [-@rem:lec07:delta-small]).
3. Запишите явное $\delta(\varepsilon) = \min(\delta_0, \ldots)$ и проверьте, что при $0 < |x - x_0| < \delta$ неравенство $|f(x) - A| < \varepsilon$ выполнено.
4. На бесконечности вместо $\delta$ ищется $C(\varepsilon)$: неравенство должно выполняться при $x > C$ (определение [-@def:lec08:general-limit]).
5. Предела нет: две последовательности Гейне с разными пределами значений или одна, на которой $f(x_n)$ расходится (следствие [-@cor:lec07:two-sequences]). Проверьте, что $x_n \ne x_0$ и $x_n \to x_0$.

::: {.problem #prob:kr2:cauchy-rational}
Докажите по определению Коши, что $\lim\limits_{x \to 1} \dfrac{x + 3}{2x + 1} = \dfrac43$.
:::

::: solution
Функция определена при $x \ne -\frac12$, в частности около точки $1$. Приведём к общему знаменателю:
$$\left|\frac{x + 3}{2x + 1} - \frac43\right| = \frac{|3x + 9 - 8x - 4|}{3|2x + 1|} = \frac{5|x - 1|}{3|2x + 1|}.$$
*Ключ:* ограничить $\delta \le \frac12$. При $|x - 1| < \frac12$ имеем $x > \frac12$ и $2x + 1 > 2$, поэтому $\left|\frac{x + 3}{2x + 1} - \frac43\right| < \frac{5}{6}|x - 1|$. Для $\varepsilon > 0$ положим $\delta = \min\left(\frac12,\ \frac{6\varepsilon}{5}\right)$. Тогда при $0 < |x - 1| < \delta$ получаем $\left|\frac{x + 3}{2x + 1} - \frac43\right| < \frac56 \cdot \frac{6\varepsilon}{5} = \varepsilon$.
:::

::: {.problem #prob:kr2:no-limit}
Докажите, что предел $\lim\limits_{x \to 0} \cos\dfrac{1}{x^2}$ не существует.
:::

::: solution
*Ключ:* подобрать точки, где $\frac{1}{x^2}$ равно $2\pi n$ и $\pi(2n + 1)$. Положим $x_n = \frac{1}{\sqrt{2\pi n}}$ и $y_n = \frac{1}{\sqrt{\pi(2n + 1)}}$. Обе последовательности не обращаются в ноль и стремятся к нулю, то есть это последовательности Гейне для точки $0$. На них $\cos\frac{1}{x_n^2} = \cos 2\pi n = 1 \to 1$ и $\cos\frac{1}{y_n^2} = \cos(\pi(2n + 1)) = -1 \to -1$. Пределы значений разные, и по следствию [-@cor:lec07:two-sequences] предела в нуле нет.
:::

Ещё задачи: [-@prob:lec07:x2-25], [-@prob:lec07:rational], [-@prob:lec07:rational2], [-@prob:lec08:definition], [-@prob:lec07:floor].

## 3. Вычисление пределов функций {#sec:kr2:limits}

1. Определите вид неопределённости и перенесите точку в ноль: при $x \to x_0$ замена $t = x - x_0$, при $x \to \infty$ часто $t = \frac1x$.
2. В произведении и частном бесконечно малые множители заменяйте эквивалентными (теорема [-@thm:lec09:replacement]) по таблице [-@prop:lec09:table] и следствию [-@cor:lec11:arc-limits], подставляя вместо $x$ бесконечно малую $u(x) \ne 0$ (утверждение [-@prop:lec09:substitution]).
3. В сумме и разности так делать нельзя (замечание [-@rem:lec09:sums]). Сначала найдите главную часть: запишите слагаемые как $kx + o(x)$ (теорема [-@thm:lec09:equiv-o]) и отбросьте $o$ (следствие [-@cor:lec09:main-part]) или превратите разность в произведение: $e^a - e^b = e^b(e^{a - b} - 1)$.
4. Неопределённость $1^\infty$: $u^v = e^{v \ln u}$, и при $u \to 1$, $u \ne 1$ имеем $\ln u \sim u - 1$. Найдите предел показателя $B$, ответ $e^B$ по непрерывности экспоненты (теорема [-@thm:lec10:composite]). Если основание стремится к $A > 0$, а показатель к конечному $B$, неопределённости нет, и предел равен $A^B$ (следствие [-@cor:lec11:power-limit]).
5. При каждой замене пишите в решении, по какой эквивалентности она сделана.

::: {.problem #prob:kr2:equiv-product}
Найдите $\lim\limits_{x \to 0} \dfrac{\ln(1 + \sin 4x)\,\bigl(e^{x^2} - 1\bigr)}{x\,(1 - \cos 2x)}$.
:::

::: solution
При $x \to 0$ все три сомножителя, кроме $x$, бесконечно малые. При малых $x \ne 0$ имеем $\sin 4x \ne 0$ и $\sin 4x \to 0$, поэтому по таблице [-@prop:lec09:table] и утверждению [-@prop:lec09:substitution] $\ln(1 + \sin 4x) \sim \sin 4x \sim 4x$. Так же $e^{x^2} - 1 \sim x^2$ и $1 - \cos 2x \sim \frac{(2x)^2}{2} = 2x^2$. По теореме [-@thm:lec09:replacement] заменяем множители:
$$\lim_{x \to 0} \frac{4x \cdot x^2}{x \cdot 2x^2} = 2.$$

*Ответ:* $2$.
:::

::: {.problem #prob:kr2:one-infinity}
Найдите $\lim\limits_{x \to 0} \left(\dfrac{1 + \operatorname{tg} 3x}{1 + \sin x}\right)^{1/x}$.
:::

::: solution
Основание $u(x) = \frac{1 + \operatorname{tg} 3x}{1 + \sin x} \to 1$, показатель $\frac1x \to \infty$: неопределённость $1^\infty$. Имеем $u - 1 = \frac{\operatorname{tg} 3x - \sin x}{1 + \sin x}$. *Ключ:* в разности $\operatorname{tg} 3x - \sin x$ заменять слагаемые эквивалентными нельзя, но можно записать их через $o$ (теорема [-@thm:lec09:equiv-o]): $\operatorname{tg} 3x = 3x + o(x)$, $\sin x = x + o(x)$, так что $\operatorname{tg} 3x - \sin x = 2x + o(x) \sim 2x$ (следствие [-@cor:lec09:main-part]). Знаменатель $1 + \sin x \to 1$, поэтому $u - 1 \sim 2x$; в частности, $u \ne 1$ при малых $x \ne 0$. Тогда $\ln u = \ln\bigl(1 + (u - 1)\bigr) \sim u - 1 \sim 2x$ и
$$\frac{\ln u}{x} \to 2, \qquad u^{1/x} = e^{\frac{\ln u}{x}} \to e^2$$
по непрерывности экспоненты (теорема [-@thm:lec10:composite]).

*Ответ:* $e^2$.
:::

Ещё задачи: [-@prob:lec08:trig], [-@prob:lec08:e-limits], [-@prob:lec08:classic], [-@prob:lec09:limits], [-@prob:lec11:limits].

## 4. Непрерывность и точки разрыва {#sec:kr2:continuity}

1. Найдите область определения. Где функция задана одной формулой из элементарных функций и все звенья определены, она непрерывна (утверждение [-@prop:lec10:elementary]).
2. Выпишите подозрительные точки: нули знаменателей, точки стыка формул, нули выражения под модулем в знаменателе.
3. В каждой найдите $f(x_0 - 0)$, $f(x_0 + 0)$ и $f(x_0)$, если она определена (раздел [-@sec:lec10:method]).
4. Род разрыва по определению [-@def:lec09:kinds]: конечные равные односторонние пределы — устранимый (доопределите функцию этим числом), конечные разные — скачок, иначе второй род.
5. С параметрами: условия непрерывности в точке стыка — уравнения $f(x_0 - 0) = f(x_0) = f(x_0 + 0)$.

::: {.problem #prob:kr2:parameters}
При каких $a$ и $b$ функция непрерывна на $\R$?
$$f(x) = \begin{cases} \dfrac{\sin 3x}{x}, & x < 0, \\ ax + b, & 0 \le x \le 2, \\ \dfrac{x^2 - 4}{x - 2}, & x > 2. \end{cases}$$
:::

::: solution
На интервалах $(-\infty;\ 0)$, $(0;\ 2)$ и $(2;\ +\infty)$ функция задана одной элементарной формулой без нулей знаменателя и непрерывна (утверждение [-@prop:lec10:elementary]). Остаются точки стыка.

В точке $0$: $f(0 - 0) = \lim\limits_{x \to 0} \frac{\sin 3x}{x} = 3$ (следствие [-@cor:lec08:consequences]), $f(0) = b$, $f(0 + 0) = b$. Непрерывность в нуле равносильна $b = 3$.

В точке $2$: $f(2 - 0) = f(2) = 2a + b = 2a + 3$, а при $x > 2$ имеем $\frac{x^2 - 4}{x - 2} = x + 2$, так что $f(2 + 0) = 4$. Условие $2a + 3 = 4$ даёт $a = \frac12$.

*Ответ:* $a = \frac12$, $b = 3$.
:::

::: {.problem #prob:kr2:classify}
Найдите точки разрыва функции $f(x) = \dfrac{x^2 - x}{|x|\,(x^2 - 1)}$, определите их род и доопределите функцию по непрерывности, где это возможно.
:::

::: solution
Область определения: $x \ne 0$, $x \ne \pm 1$; на ней функция непрерывна. *Ключ:* сократить и записать $\frac{x}{|x|} = \operatorname{sign} x$. При $x$ из области определения
$$f(x) = \frac{x(x - 1)}{|x|(x - 1)(x + 1)} = \frac{\operatorname{sign} x}{x + 1}.$$

В точке $0$: $f(0 - 0) = \frac{-1}{1} = -1$, $f(0 + 0) = 1$. Пределы конечны и различны: скачок.

В точке $1$: около неё $f(x) = \frac{1}{x + 1} \to \frac12$. Разрыв устранимый, положим $f(1) = \frac12$.

В точке $-1$: около неё $x < 0$ и $f(x) = -\frac{1}{x + 1}$, так что $f(-1 - 0) = +\infty$, $f(-1 + 0) = -\infty$. Разрыв второго рода (и прямая $x = -1$ — вертикальная асимптота).

*Ответ:* $x = 0$ — скачок; $x = 1$ — устранимый разрыв, $f(1) = \frac12$; $x = -1$ — разрыв второго рода.
:::

Ещё задачи: [-@prob:lec10:parameters], [-@prob:lec10:piecewise], [-@prob:lec10:classify], [-@prob:lec09:discontinuities], [-@prob:lec09:one-sided].

## 5. Асимптоты {#sec:kr2:asymptotes}

1. Найдите область определения. Кандидаты в вертикальные асимптоты — граничные точки области и точки разрыва; в каждой найдите односторонние пределы. Прямая $x = x_0$ — асимптота, если хотя бы один из них бесконечен (определение [-@def:lec09:asymptotes]); конечный предел асимптоты не даёт (замечание [-@rem:lec09:not-vertical]).
2. Наклонную асимптоту ищите отдельно при $x \to +\infty$ и при $x \to -\infty$: $k = \lim \frac{f(x)}{x}$, $b = \lim (f(x) - kx)$, оба предела должны быть конечны (теорема [-@thm:lec09:oblique]).
3. С корнями помните, что $\sqrt{x^2} = |x|$: при $x \to -\infty$ знак меняется, и асимптоты с двух сторон разные (пример [-@ex:lec09:two-sides]).
4. В ответе перечислите все прямые и для наклонных укажите, при каком стремлении $x$.

::: {.problem #prob:kr2:asymptotes-rational}
Найдите все асимптоты графика $f(x) = \dfrac{x^2 + 3x}{x - 1}$.
:::

::: solution
Область определения: $x \ne 1$, на ней функция непрерывна. При $x \to 1$ числитель стремится к $4$, а знаменатель к $\pm 0$, поэтому $f(1 - 0) = -\infty$, $f(1 + 0) = +\infty$: прямая $x = 1$ — вертикальная асимптота. Других вертикальных нет.

При $x \to \pm\infty$: $k = \lim \frac{x^2 + 3x}{x(x - 1)} = \lim \frac{x + 3}{x - 1} = 1$ и
$$b = \lim\left(\frac{x^2 + 3x}{x - 1} - x\right) = \lim \frac{4x}{x - 1} = 4.$$

*Ответ:* $x = 1$; $y = x + 4$ при $x \to \pm\infty$.
:::

::: {.problem #prob:kr2:asymptotes-exp}
Найдите все асимптоты графика $f(x) = x\,e^{1/x}$.
:::

::: solution
Область определения: $x \ne 0$. Односторонние пределы в нуле разные. При $x \to -0$ имеем $\frac1x \to -\infty$, $e^{1/x} \to 0$, и $f(x) \to 0$. При $x \to +0$ замена $t = \frac1x \to +\infty$ даёт $f = \frac{e^t}{t}$. *Ключ:* по неравенству $e^s > 1 + s$ (задача [-@prob:lec13:inequalities] (c)) $e^t = \left(e^{t/2}\right)^2 > \left(1 + \frac t2\right)^2 > \frac{t^2}{4}$, поэтому $\frac{e^t}{t} > \frac t4 \to +\infty$. Значит, $f(0 + 0) = +\infty$, и $x = 0$ — вертикальная асимптота (с одной стороны этого достаточно).

При $x \to \pm\infty$: $k = \lim e^{1/x} = e^0 = 1$, а с заменой $t = \frac1x \to 0$, $t \ne 0$,
$$b = \lim x\left(e^{1/x} - 1\right) = \lim_{t \to 0} \frac{e^t - 1}{t} = 1$$
(следствие [-@cor:lec08:exp]).

*Ответ:* $x = 0$ (при $x \to +0$); $y = x + 1$ при $x \to \pm\infty$.
:::

Ещё задачи: [-@prob:lec09:asymptotes], [-@ex:lec09:two-sides].

## 6. Производная по определению и дифференцируемость {#sec:kr2:diff-def}

1. Где функция задана одной формулой и все звенья дифференцируемы, производная считается по правилам (раздел [-@sec:lec12:method]).
2. Подозрительные точки: стыки формул, нули выражений под модулем и под корнем нечётной степени.
3. В каждой сначала проверьте непрерывность: без неё производной нет (теорема [-@thm:lec12:continuous]). Для параметров это первое уравнение.
4. Найдите $f'_-(x_0)$ и $f'_+(x_0)$ как пределы разностного отношения при $h \to -0$ и $h \to +0$ (определение [-@def:lec11:one-sided]). Производная есть тогда и только тогда, когда они равны.
5. Если с одной стороны и в самой точке $f$ совпадает с функцией $g$, дифференцируемой в $x_0$, то разностные отношения с этой стороны у $f$ и $g$ одинаковые, и односторонняя производная равна $g'(x_0)$. Брать вместо этого предел $f'(x)$ можно только при непрерывности $f$ в точке (следствие [-@cor:lec13:derivative-limit]).

::: {.problem #prob:kr2:abs-derivative}
Существует ли $f'(2)$ для $f(x) = x\,|x - 2|$? Найдите односторонние производные в точке $2$.
:::

::: solution
$f(2) = 0$, и разностное отношение
$$\frac{f(2 + h) - f(2)}{h} = \frac{(2 + h)|h|}{h}.$$
При $h \to +0$ оно равно $2 + h \to 2$, при $h \to -0$ равно $-(2 + h) \to -2$. Односторонние производные разные, и производной в точке $2$ нет.

*Ответ:* не существует; $f'_+(2) = 2$, $f'_-(2) = -2$.
:::

::: {.problem #prob:kr2:piecewise-diff}
При каких $a$ и $b$ функция $f(x) = \begin{cases} \operatorname{arctg} x, & x \le 1, \\ ax^2 + b, & x > 1 \end{cases}$ дифференцируема на $\R$?
:::

::: solution
При $x \ne 1$ функция дифференцируема по правилам. В точке $1$ нужна непрерывность: $f(1 - 0) = f(1) = \frac\pi4$, $f(1 + 0) = a + b$, откуда $a + b = \frac\pi4$.

Слева от $1$ и в самой точке $f = \operatorname{arctg} x$, а $\operatorname{arctg}$ дифференцируема в точке $1$, поэтому $f'_-(1) = \frac{1}{1 + 1^2} = \frac12$ (утверждение [-@prop:lec12:arc-derivatives]). Справа при $h > 0$, подставив $b = \frac\pi4 - a$,
$$\frac{f(1 + h) - f(1)}{h} = \frac{a(1 + h)^2 + b - \frac\pi4}{h} = \frac{a(1 + h)^2 - a}{h} = a(2 + h) \to 2a.$$
Условие $f'_-(1) = f'_+(1)$: $2a = \frac12$, $a = \frac14$, $b = \frac\pi4 - \frac14$.

*Ответ:* $a = \frac14$, $b = \frac{\pi - 1}{4}$.
:::

Ещё задачи: [-@prob:lec11:by-definition], [-@prob:lec11:one-sided], [-@prob:lec12:piecewise], [-@prob:lec12:true-false].

## 7. Вычисление производных и касательная {#sec:kr2:rules}

1. Разберите функцию на звенья. Производная — по таблице [-@prop:lec11:table], утверждению [-@prop:lec12:arc-derivatives] и правилам [-@thm:lec12:arithmetic], [-@thm:lec12:chain].
2. Функцию вида $u^v$ дифференцируйте через $u^v = e^{v \ln u}$: $(u^v)' = u^v\left(v' \ln u + \frac{v u'}{u}\right)$ (раздел [-@sec:lec12:log-diff]).
3. Производная обратной в точке $y_0$: найдите $x_0$ с $f(x_0) = y_0$, проверьте строгую монотонность и $f'(x_0) \ne 0$, тогда $(f^{-1})'(y_0) = \frac{1}{f'(x_0)}$ (теорема [-@thm:lec12:inverse]).
4. Касательная: $y = f(x_0) + f'(x_0)(x - x_0)$ (определение [-@def:lec11:tangent]); у кривой, заданной параметрически, наклон $\frac{y'_t}{x'_t}$ (утверждение [-@prop:lec13:parametric]).
5. Упростите производную, прежде чем подставлять точку: слагаемые часто сокращаются.

::: {.problem #prob:kr2:derivative-tangent}
Найдите производную функции $y = x \arcsin\dfrac x2 + \sqrt{4 - x^2}$ на $(-2;\ 2)$ и уравнение касательной к её графику в точке с абсциссой $1$.
:::

::: solution
По правилу произведения и производной сложной функции
$$\left(x \arcsin\frac x2\right)' = \arcsin\frac x2 + x \cdot \frac{1}{\sqrt{1 - x^2/4}} \cdot \frac12 = \arcsin\frac x2 + \frac{x}{\sqrt{4 - x^2}},$$
так как $2\sqrt{1 - \frac{x^2}{4}} = \sqrt{4 - x^2}$. Далее $\left(\sqrt{4 - x^2}\right)' = \frac{-2x}{2\sqrt{4 - x^2}} = -\frac{x}{\sqrt{4 - x^2}}$. Слагаемые с корнем сокращаются: $y' = \arcsin\frac x2$.

В точке $1$: $y(1) = \arcsin\frac12 + \sqrt3 = \frac\pi6 + \sqrt3$, $y'(1) = \frac\pi6$. Касательная: $y = \frac\pi6 + \sqrt3 + \frac\pi6(x - 1) = \frac\pi6 x + \sqrt3$.

*Ответ:* $y' = \arcsin\frac x2$; касательная $y = \frac\pi6 x + \sqrt3$.
:::

::: {.problem #prob:kr2:log-diff}
Найдите $y'(1)$ для $y = (x^2 + 1)^{\operatorname{arctg} x}$.
:::

::: solution
Основание $x^2 + 1 > 0$, поэтому $y = e^{\operatorname{arctg} x \cdot \ln(x^2 + 1)}$ и по правилу для сложной функции
$$y' = (x^2 + 1)^{\operatorname{arctg} x}\left(\frac{\ln(x^2 + 1)}{1 + x^2} + \operatorname{arctg} x \cdot \frac{2x}{x^2 + 1}\right).$$
При $x = 1$: $y(1) = 2^{\pi/4}$, скобка равна $\frac{\ln 2}{2} + \frac\pi4 \cdot \frac22 = \frac{\ln 2}{2} + \frac\pi4$.

*Ответ:* $y'(1) = 2^{\pi/4}\left(\dfrac{\ln 2}{2} + \dfrac\pi4\right)$.
:::

Ещё задачи: [-@prob:lec12:rules], [-@prob:lec12:log-diff], [-@prob:lec12:inverse], [-@prob:lec12:tangent], [-@prob:lec11:tangent], [-@prob:lec13:parametric].

## 8. Монотонность, экстремумы, наибольшее и наименьшее значения {#sec:kr2:extrema}

1. Найдите область определения, производную и критические точки: нули $f'$ и точки, где $f$ определена, а производной нет (определение [-@def:lec13:critical]).
2. Наибольшее и наименьшее значения на отрезке: сравните значения на концах и в критических точках внутри (утверждение [-@prop:lec13:max-min]). Классифицировать точки не нужно; не теряйте концы и изломы (замечание [-@rem:lec13:max-min-traps]).
3. Промежутки монотонности: знак $f'$ на интервалах между критическими точками, затем замечание [-@rem:kr2:monotone]. Концы промежутков, в которых $f$ непрерывна, включайте.
4. Экстремум: знак $f'$ меняется с плюса на минус — максимум, с минуса на плюс — минимум, не меняется — экстремума нет, как у $x^3$ в нуле (замечание [-@rem:lec13:fermat-converse]).
5. На интервале или луче теоремы Вейерштрасса нет: наибольшее и наименьшее значения находите по промежуткам монотонности и пределам на концах.

::: {.remark #rem:kr2:monotone title="достаточное условие монотонности"}
Пусть $f$ непрерывна на промежутке $I$ и $f'(x) > 0$ во всех внутренних точках $I$. Тогда $f$ строго возрастает на $I$. Действительно, для $x_1 < x_2$ из $I$ функция непрерывна на $[x_1;\ x_2]$ и дифференцируема на $(x_1;\ x_2)$, и по теореме Лагранжа [-@thm:lec13:lagrange] $f(x_2) - f(x_1) = f'(c)(x_2 - x_1) > 0$. Так же при $f' < 0$ функция строго убывает, при $f' \ge 0$ не убывает. Отсюда признак экстремума: если $f$ непрерывна в $x_0$, $f' > 0$ на $(x_0 - \delta;\ x_0)$ и $f' < 0$ на $(x_0;\ x_0 + \delta)$, то $f$ возрастает на $(x_0 - \delta;\ x_0]$ и убывает на $[x_0;\ x_0 + \delta)$, и $x_0$ — точка строгого максимума. Для минимума знаки наоборот.
:::

::: {.problem #prob:kr2:max-min}
Найдите наибольшее и наименьшее значения функции $f(x) = 2x^3 - 3x^2 - 12x + 1$ на отрезке $[-2;\ 3]$.
:::

::: solution
$f'(x) = 6x^2 - 6x - 12 = 6(x + 1)(x - 2)$, критические точки $-1$ и $2$, обе внутри отрезка; производная существует всюду. Значения:
$$f(-2) = -3, \qquad f(-1) = 8, \qquad f(2) = -19, \qquad f(3) = -8.$$

*Ответ:* наибольшее значение $8$ (в точке $-1$), наименьшее $-19$ (в точке $2$).
:::

::: {.problem #prob:kr2:monotone-cusp}
Найдите промежутки монотонности и точки экстремума функции $f(x) = \sqrt[3]{x^2}\,(x - 5)$.
:::

::: solution
Функция определена и непрерывна на $\R$. При $x \ne 0$ имеем $\left(\sqrt[3]{x^2}\right)' = \left(\sqrt[3]{x}^{\,2}\right)' = 2\sqrt[3]{x} \cdot \frac{1}{3\sqrt[3]{x^2}} = \frac{2}{3\sqrt[3]{x}}$ (пример [-@ex:lec12:chain] (e)), и
$$f'(x) = \frac{2(x - 5)}{3\sqrt[3]{x}} + \sqrt[3]{x^2} = \frac{2(x - 5) + 3x}{3\sqrt[3]{x}} = \frac{5(x - 2)}{3\sqrt[3]{x}}.$$
*Ключ:* точка $0$ тоже критическая. Разностное отношение $\frac{f(h) - f(0)}{h} = \frac{h - 5}{\sqrt[3]{h}}$ стремится к $\mp\infty$ при $h \to \pm 0$, производной в нуле нет. Критические точки: $0$ и $2$.

Знак $f'$: при $x < 0$ числитель и знаменатель отрицательны, $f' > 0$; при $0 < x < 2$ числитель отрицателен, знаменатель положителен, $f' < 0$; при $x > 2$ оба положительны, $f' > 0$. По замечанию [-@rem:kr2:monotone] $f$ строго возрастает на $(-\infty;\ 0]$, строго убывает на $[0;\ 2]$ и строго возрастает на $[2;\ +\infty)$. В точке $0$ возрастание сменяется убыванием: максимум, $f(0) = 0$. В точке $2$ наоборот: минимум, $f(2) = \sqrt[3]{4} \cdot (-3) = -3\sqrt[3]{4}$.

*Ответ:* возрастает на $(-\infty;\ 0]$ и на $[2;\ +\infty)$, убывает на $[0;\ 2]$; $x = 0$ — точка максимума ($f(0) = 0$), $x = 2$ — точка минимума ($f(2) = -3\sqrt[3]{4}$).
:::

Ещё задачи: [-@prob:lec13:max-min], [-@prob:lec13:optimization], [-@ex:lec13:max-min], [-@prob:lec10:extrema].

## 9. Теоремы Ролля и Лагранжа: корни и неравенства {#sec:kr2:mean-value}

1. Число корней уравнения $f(x) = 0$. Существование — теорема Больцано–Коши на отрезках, где $f$ меняет знак (теорема [-@thm:lec10:bolzano-cauchy]). Оценка сверху — если у $f'$ не больше $k$ корней, у $f$ не больше $k + 1$ (следствие [-@cor:lec13:roots]).
2. Неравенство: запишите разность как приращение функции $f(b) - f(a)$, примените теорему Лагранжа [-@thm:lec13:lagrange] и оцените $f'(c)$, пользуясь тем, что $c$ лежит между $a$ и $b$.
3. Тождество: производная разности частей равна нулю на промежутке, значит, разность постоянна (следствие [-@cor:lec13:constant]); константу найдите подстановкой точки, концы промежутка присоедините по непрерывности.
4. Найти точку $c$ из теоремы Ролля, Лагранжа или Коши: проверьте условия (непрерывность на отрезке, дифференцируемость внутри, у Коши $g' \ne 0$), решите уравнение на $c$ и проверьте, что $c \in (a;\ b)$.

::: {.problem #prob:kr2:three-roots}
Сколько действительных корней у уравнения $x^3 - 3x + 1 = 0$?
:::

::: solution
Пусть $f(x) = x^3 - 3x + 1$. Производная $f'(x) = 3x^2 - 3$ обращается в ноль только в точках $\pm 1$, поэтому по следствию [-@cor:lec13:roots] у $f$ не больше трёх корней. С другой стороны,
$$f(-2) = -1 < 0, \qquad f(-1) = 3 > 0, \qquad f(1) = -1 < 0, \qquad f(2) = 3 > 0,$$
и по теореме Больцано–Коши на каждом из интервалов $(-2;\ -1)$, $(-1;\ 1)$, $(1;\ 2)$ есть корень. Интервалы не пересекаются, корни разные.

*Ответ:* три.
:::

::: {.problem #prob:kr2:arctg-bounds}
Докажите, что $\dfrac{x}{1 + x^2} < \operatorname{arctg} x < x$ при $x > 0$.
:::

::: solution
Функция $\operatorname{arctg}$ дифференцируема на $\R$. По теореме Лагранжа на $[0;\ x]$ найдётся $c \in (0;\ x)$ с
$$\operatorname{arctg} x - \operatorname{arctg} 0 = \frac{1}{1 + c^2}\,x.$$
Из $0 < c < x$ следует $1 < 1 + c^2 < 1 + x^2$, то есть $\frac{1}{1 + x^2} < \frac{1}{1 + c^2} < 1$. Умножив на $x > 0$, получаем требуемое.
:::

Ещё задачи: [-@prob:lec13:roots], [-@prob:lec13:inequalities], [-@prob:lec13:conditions], [-@prob:lec13:identity], [-@prob:lec10:roots].

# Определения

::: {.definition ref="def:lec06:fundamental"}
$(a_n)$ фундаментальна, если $\forall \varepsilon > 0\ \exists N\ \forall m, n > N\colon |a_m - a_n| < \varepsilon$.
:::

::: {.theorem ref="thm:lec06:cauchy"}
Последовательность сходится тогда и только тогда, когда она фундаментальна.
:::

::: {.proposition ref="prop:lec06:split"}
Если $\N$ разбито на конечное число бесконечных частей и на $j$-й части подпоследовательность стремится к $L_j$, то частичные пределы последовательности — ровно $L_1, \dots, L_p$.
:::

::: {.definition ref="def:lec07:cauchy-limit"}
$\lim\limits_{x \to x_0} f(x) = A$, если $\forall \varepsilon > 0\ \exists \delta > 0\ \forall x\colon 0 < |x - x_0| < \delta \Rightarrow |f(x) - A| < \varepsilon$.
:::

::: {.corollary ref="cor:lec07:two-sequences"}
Если для двух последовательностей Гейне $f(x_n) \to A$, $f(y_n) \to B$, $A \ne B$, или для одной $f(x_n)$ расходится, то предела в точке $x_0$ нет.
:::

::: {.proposition ref="prop:lec09:table"}
При $x \to 0$: $\sin x \sim \operatorname{tg} x \sim \ln(1 + x) \sim e^x - 1 \sim x$, $1 - \cos x \sim \frac{x^2}{2}$, $(1 + x)^\alpha - 1 \sim \alpha x$.
:::

::: {.corollary ref="cor:lec11:arc-limits"}
$\arcsin x \sim x$ и $\operatorname{arctg} x \sim x$ при $x \to 0$.
:::

::: {.theorem ref="thm:lec09:replacement"}
Множитель в произведении или частном можно заменить эквивалентным: пределы существуют или нет одновременно и равны.
:::

::: {.definition ref="def:lec09:kinds"}
Устранимый разрыв — конечный предел есть, но не равен $f(x_0)$ или $f(x_0)$ не определено; скачок — односторонние пределы конечны и различны; второй род — остальные случаи.
:::

::: {.theorem ref="thm:lec09:oblique"}
$y = kx + b$ — наклонная асимптота при $x \to +\infty$ тогда и только тогда, когда $k = \lim \frac{f(x)}{x}$ и $b = \lim (f(x) - kx)$ существуют и конечны.
:::

::: {.definition ref="def:lec11:derivative"}
$f'(x_0) = \lim\limits_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h}$, если предел существует и конечен.
:::

::: {.theorem ref="thm:lec12:chain"}
$\bigl(f(g(x))\bigr)' = f'(g(x)) \cdot g'(x)$, если $g$ дифференцируема в $x$, а $f$ — в $g(x)$.
:::

::: {.theorem ref="thm:lec12:inverse"}
Если $f$ непрерывна и строго монотонна на промежутке, $x_0$ внутри и $f'(x_0) \ne 0$, то $(f^{-1})'(f(x_0)) = \frac{1}{f'(x_0)}$.
:::

::: {.theorem ref="thm:lec13:fermat"}
Если $x_0$ — точка локального экстремума и $f'(x_0)$ существует, то $f'(x_0) = 0$.
:::

::: {.theorem ref="thm:lec13:rolle"}
Если $f$ непрерывна на $[a;\ b]$, дифференцируема на $(a;\ b)$ и $f(a) = f(b)$, то $f'(c) = 0$ для некоторого $c \in (a;\ b)$.
:::

::: {.theorem ref="thm:lec13:lagrange"}
Если $f$ непрерывна на $[a;\ b]$ и дифференцируема на $(a;\ b)$, то $f(b) - f(a) = f'(c)(b - a)$ для некоторого $c \in (a;\ b)$.
:::

::: {.theorem ref="thm:lec13:cauchy"}
Если $f$, $g$ непрерывны на $[a;\ b]$, дифференцируемы на $(a;\ b)$ и $g' \ne 0$ на $(a;\ b)$, то $\frac{f(b) - f(a)}{g(b) - g(a)} = \frac{f'(c)}{g'(c)}$ для некоторого $c \in (a;\ b)$.
:::

::: {.corollary ref="cor:lec13:constant"}
Если $f' = 0$ на промежутке, то $f$ постоянна на нём.
:::
