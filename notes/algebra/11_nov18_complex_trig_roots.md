# Контекст

В лекции 10 комплексные числа введены как пары $(x, y) = x + iy$ с умножением, при котором $i^2 = -1$, и выведено правило умножения в алгебраической форме. Остались вопросы. Законно ли раскрывать скобки «как у многочленов от $i$», то есть выполнены ли для комплексных чисел привычные свойства операций? Как делить? Есть ли у умножения геометрический смысл и как решать уравнения вида $z^n = w$? Сегодня проверим девять свойств операций (аксиомы поля), научимся делить с помощью сопряжения, введём модуль, аргумент и тригонометрическую форму, в которой умножение — поворот и растяжение, выведем формулу Муавра, найдём все корни $n$-й степени и запишем формулу Эйлера. В конце — многочлены с комплексными коэффициентами и основная теорема алгебры: у каждого такого многочлена положительной степени есть комплексный корень.

# После прочтения ты сможешь

- проверять свойства операций над комплексными числами и объяснять, почему в $\mathbb{C}$ работают формулы сокращённого умножения и формула корней квадратного уравнения;
- находить сопряжённое и делить комплексные числа в алгебраической форме, решать уравнения с $z$ и $\bar z$;
- переводить комплексное число из алгебраической формы в тригонометрическую и показательную и обратно, выбирая аргумент по знакам действительной и мнимой частей;
- умножать, делить и возводить в степень числа в тригонометрической форме, в том числе по формуле Муавра;
- находить все корни $n$-й степени из комплексного числа, изображать их на комплексной плоскости вместе с исходным числом и выбирать корни с условием на аргумент;
- решать системы линейных уравнений с комплексными коэффициентами;
- выражать $\cos n\varphi$ и $\sin n\varphi$ через $\cos \varphi$ и $\sin \varphi$, а степени синуса и косинуса — через синусы и косинусы кратных углов.

# Теория

## Свойства операций над комплексными числами {#sec:lec11:field}

В лекции 10 произведение $(x_1 + iy_1)(x_2 + iy_2)$ считалось раскрытием скобок с заменой $i^2$ на $-1$. Раскрывать скобки по привычным правилам можно только там, где выполнены привычные свойства, а они выполнены не всегда: для матриц $AB \ne BA$ (пример [-@ex:lec02:noncomm]), поэтому $(A + B)^2 \ne A^2 + 2AB + B^2$. Для комплексных чисел свойства нужно проверить.

::: {.proposition #prop:lec11:field title="свойства сложения и умножения"}
Для любых $z, z_1, z_2, z_3 \in \mathbb{C}$:

1. $z_1 + z_2 = z_2 + z_1$ (коммутативность сложения);
2. $(z_1 + z_2) + z_3 = z_1 + (z_2 + z_3)$ (ассоциативность сложения);
3. существует нейтральный элемент по сложению — «ноль»: $z + 0 = 0 + z = z$, здесь $0 = (0, 0)$;
4. для каждого $z$ существует противоположный $-z = (-x, -y)$: $z + (-z) = (-z) + z = 0$;
5. $z_1 z_2 = z_2 z_1$ (коммутативность умножения);
6. $(z_1 z_2) z_3 = z_1 (z_2 z_3)$ (ассоциативность умножения);
7. существует нейтральный элемент по умножению — «единица»: $z \cdot 1 = 1 \cdot z = z$, здесь $1 = (1, 0)$;
8. для каждого $z \ne 0$ существует обратный $z^{-1} \in \mathbb{C}$: $z z^{-1} = z^{-1} z = 1$;
9. $z_1 (z_2 + z_3) = z_1 z_2 + z_1 z_3$ (дистрибутивность умножения относительно сложения).
:::

::: proof
Свойства 1–4 сложения проверяются покомпонентно и наследуются от $\R$. Свойство 5: формула умножения [-@eq:lec10:operations] не меняется при перестановке индексов $1 \leftrightarrow 2$. Свойство 7: $(x, y) \cdot (1, 0) = (x \cdot 1 - y \cdot 0, \; x \cdot 0 + 1 \cdot y) = (x, y)$.

Свойство 9. Пусть $z_k = x_k + iy_k$. Действительная часть левой части равна $x_1 (x_2 + x_3) - y_1 (y_2 + y_3)$, правой — $(x_1 x_2 - y_1 y_2) + (x_1 x_3 - y_1 y_3)$; это одно и то же. Мнимые части: $x_1 (y_2 + y_3) + (x_2 + x_3) y_1$ и $(x_1 y_2 + x_2 y_1) + (x_1 y_3 + x_3 y_1)$ — тоже равны. Свойство 6 проверяется так же: действительная часть обеих сторон равна $x_1 x_2 x_3 - x_1 y_2 y_3 - y_1 x_2 y_3 - y_1 y_2 x_3$, мнимая — $x_1 x_2 y_3 + x_1 y_2 x_3 + y_1 x_2 x_3 - y_1 y_2 y_3$.

Для свойства 8 нужно предъявить обратное число; это сделано ниже, после сопряжения (утверждение [-@prop:lec11:complex-division]).
:::

Дистрибутивность достаточно проверить с одной стороны: с другой она следует из коммутативности. Для матриц, где умножение не коммутативно, обе дистрибутивности пришлось проверять отдельно (теорема [-@thm:lec02:distributive]).

::: {.remark #rem:lec11:field title="поле"}
Свойства 1–9 — аксиомы *числового поля* (field), и именно они позволяют называть комплексные числа числами. Поля — $\Q$, $\R$, а теперь и $\mathbb{C}$. Матрицы $M_n(\R)$ при $n \ge 2$ числами не являются: умножение не коммутативно (нарушено свойство 5) и есть ненулевые вырожденные матрицы без обратной (нарушено свойство 8). Общее определение поля и другие примеры — в модуле 3. Сейчас важно следствие: всё, что в школе выводилось только из свойств 1–9, верно и в $\mathbb{C}$. Это формулы сокращённого умножения, бином Ньютона, формула суммы геометрической прогрессии и формула корней квадратного уравнения (замечание [-@rem:lec11:quadratic] ниже). То же с линейной алгеброй лекций 1–10: метод Гаусса, определители и правило Крамера используют только сложение, умножение и деление чисел, поэтому системы линейных уравнений с комплексными коэффициентами решаются теми же способами (задача [-@prob:lec11:linear-system]).
:::

::: {.remark #rem:lec11:no-order tag="частое заблуждение"}
«*$i > 0$, ведь $i$ лежит выше нуля на комплексной плоскости.*» Нет: сравнивать комплексные числа знаками $<$, $>$ нельзя. Если бы существовал порядок со школьными свойствами («произведение двух положительных положительно», «если $a > 0$, то $-a < 0$»), то при $i > 0$ было бы $i \cdot i = -1 > 0$, а при $i < 0$ — $(-i)(-i) = -1 > 0$; оба варианта противоречат $1 > 0$. Неравенства в $\mathbb{C}$ пишут только для вещественных величин: модулей, действительных и мнимых частей.
:::

## Комплексное сопряжение и деление {#sec:lec11:conjugate}

Чтобы доказать свойство 8, нужно научиться делить в алгебраической форме, то есть избавляться от комплексного знаменателя. Для этого служит сопряжение.

::: {.definition #def:lec11:conjugate title="комплексное сопряжение"}
*Комплексным сопряжением* называется смена знака мнимой части: число $\bar z = \overline{x + iy} = x - iy$ называется *сопряжённым* к $z = x + iy$.
:::

Геометрически $\bar z$ — отражение точки $z$ относительно действительной оси: у $3 + 2i$ сопряжённое $3 - 2i$.

::: {.proposition #prop:lec11:conjugate title="свойства сопряжения"}
Для любых $z, z_1, z_2 \in \mathbb{C}$:

1. $\overline{z_1 + z_2} = \bar z_1 + \bar z_2$;
2. $\overline{z_1 z_2} = \bar z_1 \cdot \bar z_2$;
3. $\bar z = z$ тогда и только тогда, когда $z \in \R$;
4. $z \bar z = x^2 + y^2$, где $z = x + iy$, — вещественное неотрицательное число, равное нулю только при $z = 0$.
:::

::: proof
Пункты 1 и 3 проверяются сравнением действительных и мнимых частей; например, в п. 3 $x - iy = x + iy$ равносильно $-y = y$, то есть $y = 0$. Пункт 2: при $z_k = x_k + iy_k$
$$\bar z_1 \bar z_2 = (x_1 - iy_1)(x_2 - iy_2) = (x_1 x_2 - y_1 y_2) - i(x_1 y_2 + x_2 y_1),$$
а это ровно $\overline{z_1 z_2}$: у $z_1 z_2$ те же действительная и мнимая части, только мнимая с плюсом. Пункт 4 — разность квадратов:
$$z \bar z = (x + iy)(x - iy) = x^2 - i^2 y^2 = x^2 + y^2,$$ {#eq:lec11:z-zbar}
а сумма квадратов вещественных чисел неотрицательна и равна нулю только при $x = y = 0$.
:::

На числах: $z_1 = 2 + 3i$, $z_2 = 1 - 2i$. В примере [-@ex:lec10:product] $z_1 z_2 = 8 - i$, значит, $\overline{z_1 z_2} = 8 + i$. С другой стороны, $\bar z_1 \bar z_2 = (2 - 3i)(1 + 2i) = 2 + 4i - 3i - 6i^2 = 8 + i$. По пунктам 1 и 2 сопряжение можно переносить на каждое слагаемое и каждый множитель: если $f$ — многочлен с вещественными коэффициентами, то $\overline{f(z)} = f(\bar z)$. Это понадобится в лекции 12.

Число $\sqrt{x^2 + y^2}$ — расстояние от точки $z$ до нуля; оно называется модулем $|z|$ (определение [-@def:lec11:modulus] ниже). Пункт 4 в этих обозначениях: $z \bar z = |z|^2$.

::: {.proposition #prop:lec11:complex-division title="обратное число и деление в алгебраической форме"}
Если $z \ne 0$, то обратное число существует и равно
$$z^{-1} = \frac{1}{z} = \frac{\bar z}{z \bar z} = \frac{\bar z}{|z|^2} = \frac{x}{x^2 + y^2} - i \, \frac{y}{x^2 + y^2}.$$
Поэтому для любых $z_1$ и $z_2 \ne 0$ частное $\dfrac{z_1}{z_2} = z_1 z_2^{-1}$ — комплексное число, и
$$\frac{z_1}{z_2} = \frac{z_1 \bar z_2}{z_2 \bar z_2} = \frac{z_1 \bar z_2}{|z_2|^2}.$$ {#eq:lec11:division}
:::

::: proof
Знаменатель $|z|^2 = x^2 + y^2$ — положительное вещественное число (свойство 4 сопряжения), поэтому $\frac{\bar z}{|z|^2}$ — комплексное число в алгебраической форме: действительная и мнимая части $\bar z$, делённые на $|z|^2$. Проверка: $z \cdot \frac{\bar z}{|z|^2} = \frac{z \bar z}{|z|^2} = 1$. Это доказывает свойство 8 утверждения [-@prop:lec11:field]. Формула для частного получается умножением на $z_2^{-1}$.
:::

На практике делят так: *числитель и знаменатель умножают на число, сопряжённое знаменателю*; знаменатель становится вещественным, $|z_2|^2$, и остаётся разделить на него действительную и мнимую части числителя. Это тот же приём, что избавление от иррациональности в знаменателе: $\dfrac{1}{1 + \sqrt 2} = \dfrac{\sqrt 2 - 1}{(\sqrt 2 + 1)(\sqrt 2 - 1)} = \sqrt 2 - 1$.

::: {.example #ex:lec11:inverse}
Найдём $(2 - 3i)^{-1}$ и $\dfrac{8 - i}{1 - 2i}$.

$(2 - 3i)^{-1} = \dfrac{2 + 3i}{(2 - 3i)(2 + 3i)} = \dfrac{2 + 3i}{2^2 + 3^2} = \dfrac{2}{13} + \dfrac{3}{13} i$. Проверка: $(2 - 3i)(2 + 3i) = 13$, так что произведение $(2 - 3i) \cdot \frac{2 + 3i}{13} = 1$. Второе: $\dfrac{(8 - i)(1 + 2i)}{(1 - 2i)(1 + 2i)} = \dfrac{8 + 16i - i - 2i^2}{1 + 4} = \dfrac{10 + 15i}{5} = 2 + 3i$. Это согласуется с примером [-@ex:lec10:product]: там $(2 + 3i)(1 - 2i) = 8 - i$.

*Ответ:* $\frac{2}{13} + \frac{3}{13} i$; $2 + 3i$.
:::

::: {.remark #rem:lec11:division-zero tag="корнер-кейс"}
На ноль делить нельзя: у $0$ обратного нет, ведь $0 \cdot w = 0 \ne 1$ при любом $w$. Зато произведение ненулевых комплексных чисел никогда не равно нулю: если $z_1 z_2 = 0$ и $z_2 \ne 0$, то $z_1 = z_1 z_2 \cdot z_2^{-1} = 0$. У матриц так не бывает: $\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}^2 = O$.
:::

::: {.remark #rem:lec11:quadratic}
Уравнение $az^2 + bz + c = 0$ с комплексными $a \ne 0$, $b$, $c$ решается по школьной формуле $z = \dfrac{-b + d}{2a}$, где $d$ пробегает оба квадратных корня из дискриминанта $D = b^2 - 4ac$, то есть оба числа с $d^2 = D$. Вывод формулы (выделение полного квадрата) использует только свойства 1–9. Запись «$\pm \sqrt{D}$» здесь означает «$d$ и $-d$», а квадратный корень из комплексного $D$ находят, как в задаче [-@prob:lec10:sqrt] или по теореме [-@thm:lec11:roots] ниже. Например, у $z^2 + 2z + 5 = 0$ дискриминант $-16$, его корни $\pm 4i$, и $z = -1 \pm 2i$ — как в примере [-@ex:lec10:product]. При $D = 0$ корень один: $z = -\frac{b}{2a}$.
:::

## Тригонометрическая форма {#sec:lec11:trig}

Возведём $1 + i$ в восьмую степень в алгебраической форме: $(1 + i)^2 = 2i$, $(2i)^2 = -4$, $(-4)^2 = 16$. Ответ получился, но что произошло с числом, по выкладке не видно. А $(1 + i\sqrt3)^{20}$ так считать долго: приходится искать удачную степень вроде куба (пример [-@ex:lec11:moivre] ниже). Точку плоскости можно задать не только декартовыми координатами $(x, y)$, но и полярными: расстоянием до начала координат и углом с положительной полуосью (рис. [-@fig:lec11:trig]). В этих координатах, как мы увидим, умножение устроено просто.

```{.tikz #fig:lec11:trig caption="Модуль и аргумент: число $z = x + iy$ — точка на расстоянии $r = |z|$ от нуля, луч к ней образует угол $\varphi$ с положительной действительной полуосью; $x = r\cos\varphi$, $y = r\sin\varphi$"}
\begin{tikzpicture}[scale=1.1]
  \draw[->] (-0.8,0) -- (4.7,0) node[below] {$\operatorname{Re}$};
  \draw[->] (0,-0.6) -- (0,2.8) node[left] {$\operatorname{Im}$};
  \draw[aux] (3,0) -- (3,2);
  \draw[aux] (0,2) -- (3,2);
  \draw[thick, nbblue, -{Stealth}] (0,0) -- (3,2) node[midway, above left] {$r = |z|$};
  \node[dot, nbblue] at (3,2) {};
  \node[above right, nbblue] at (3,2) {$z = x + iy$};
  \draw[nbred, thick, ->] (0.9,0) arc[start angle=0, end angle=33.7, radius=0.9];
  \node[nbred] at (1.25,0.33) {$\varphi$};
  \node[below] at (3,0) {$x = r\cos\varphi$};
  \node[left] at (0,2) {$y = r\sin\varphi$};
\end{tikzpicture}
```

::: {.definition #def:lec11:modulus title="модуль комплексного числа"}
*Модулем* числа $z = x + iy$ называется вещественное число $|z| = \sqrt{x^2 + y^2}$ — расстояние от точки $z$ до начала координат.
:::

По формуле [-@eq:lec11:z-zbar] $|z|^2 = z \bar z$. Для вещественного $z = x$ модуль $\sqrt{x^2}$ — обычный модуль числа $x$, так что определение его продолжает. Модуль разности $|z_1 - z_2|$ — расстояние между точками $z_1$ и $z_2$. По определению $|\bar z| = \sqrt{x^2 + (-y)^2} = |z|$ (отражение относительно вещественной оси сохраняет расстояние до нуля), а из рисунка видны оценки $|\operatorname{Re} z| \le |z|$ и $|\operatorname{Im} z| \le |z|$.

::: {.definition #def:lec11:argument title="аргумент"}
Пусть $z \ne 0$. *Аргументом* числа $z$ называется любой угол $\varphi$, для которого
$$\cos \varphi = \frac{x}{|z|}, \qquad \sin \varphi = \frac{y}{|z|},$$
то есть угол между положительной действительной полуосью и лучом из $0$ в $z$, отсчитанный против часовой стрелки (рис. [-@fig:lec11:trig]). Аргумент определён с точностью до $2\pi k$, $k \in \Z$; множество всех аргументов обозначают $\operatorname{Arg} z$. *Главное значение аргумента* $\arg z$ — тот аргумент, который лежит в полуинтервале $(-\pi, \pi]$.
:::

::: {.remark #rem:lec11:arg-convention tag="соглашение курса"}
Главное значение аргумента выбирают на полуинтервале длины $2\pi$; обычно это $[0, 2\pi)$ или $(-\pi, \pi]$, и в литературе встречаются оба варианта. В этом конспекте $\arg z \in (-\pi, \pi]$. Ответ, записанный через $\operatorname{Arg} z$ или с «$+ 2\pi k$», от выбора не зависит; например, $\arg(-i) = -\frac{\pi}{2}$ в нашем соглашении и $\frac{3\pi}{2}$ в другом, а $\operatorname{Arg}(-i) = \{ -\frac{\pi}{2} + 2\pi k : k \in \Z \}$ — одно и то же множество.
:::

::: {.remark #rem:lec11:zero-arg tag="корнер-кейс"}
У числа $0$ аргумента нет: $|0| = 0$, и в определении пришлось бы делить на ноль. Геометрически: из нуля в ноль нет луча, угол не определён. Поэтому все формулы с аргументом ниже — для $z \ne 0$.
:::

Так как $x = |z| \cos \varphi$ и $y = |z| \sin \varphi$, любое ненулевое число записывается в виде
$$z = r(\cos \varphi + i \sin \varphi), \qquad r = |z| > 0, \quad \varphi \in \operatorname{Arg} z.$$ {#eq:lec11:trig}

::: {.definition #def:lec11:trig-form title="тригонометрическая форма"}
Запись [-@eq:lec11:trig] с $r > 0$ и вещественным $\varphi$ называется *тригонометрической формой* комплексного числа $z \ne 0$.
:::

Обратно, если $z = r(\cos \varphi + i \sin \varphi)$ с $r > 0$, то $|z| = r\sqrt{\cos^2 \varphi + \sin^2 \varphi} = r$, а $\varphi$ — аргумент $z$. Значит, два числа в тригонометрической форме
$$r_1(\cos \varphi_1 + i \sin \varphi_1) = r_2(\cos \varphi_2 + i \sin \varphi_2) \;\Leftrightarrow\; r_1 = r_2 \text{ и } \varphi_1 - \varphi_2 = 2\pi k \text{ для некоторого } k \in \Z.$$ {#eq:lec11:trig-equal}
Это равенство понадобится при извлечении корней.

::: {.example #ex:lec11:trig-forms}
Запишем в тригонометрической форме $1 - i\sqrt3$, $1 + i\sqrt3$, $-1 - i$, $-5$ и $3i$.

Для $1 - i\sqrt3$: $r = \sqrt{1 + 3} = 2$, и $1 - i\sqrt3 = 2\left(\frac12 - \frac{\sqrt3}{2} i\right)$, так что $\cos \varphi = \frac12$, $\sin \varphi = -\frac{\sqrt3}{2}$. Косинусу $\frac12$ отвечают углы $\pm\frac{\pi}{3}$, а знак синуса выбирает $\varphi = -\frac{\pi}{3}$: $1 - i\sqrt3 = 2\left(\cos\left(-\frac{\pi}{3}\right) + i \sin\left(-\frac{\pi}{3}\right)\right)$. Отрицательный угол так и оставляем; если он мешает, к нему можно прибавить $2\pi$. Для $1 + i\sqrt3$: $r = \sqrt{1 + 3} = 2$, $\cos \varphi = \frac12$, $\sin \varphi = \frac{\sqrt3}{2}$, $\varphi = \frac{\pi}{3}$. Для $-1 - i$: $r = \sqrt2$, $\cos \varphi = \sin \varphi = -\frac{1}{\sqrt2}$; оба отрицательны, точка в третьей четверти, $\varphi = -\frac{3\pi}{4}$. Числа $-5$ и $3i$ лежат на осях: $\arg(-5) = \pi$, $\arg(3i) = \frac{\pi}{2}$, модули $5$ и $3$.

*Ответ:* $2(\cos(-\frac{\pi}{3}) + i \sin(-\frac{\pi}{3}))$, $2(\cos \frac{\pi}{3} + i \sin \frac{\pi}{3})$, $\sqrt2 (\cos(-\frac{3\pi}{4}) + i \sin(-\frac{3\pi}{4}))$, $5(\cos \pi + i \sin \pi)$, $3(\cos \frac{\pi}{2} + i \sin \frac{\pi}{2})$.
:::

::: {.remark #rem:lec11:arctan-trap tag="подводный камень"}
Аргумент часто ищут по формуле $\varphi = \operatorname{arctg} \frac{y}{x}$. Для $z = -1 - i$ она даёт $\operatorname{arctg} 1 = \frac{\pi}{4}$, но $\cos \frac{\pi}{4} > 0$, а у $z$ действительная часть отрицательна: это аргумент числа $1 + i$, а не $-1 - i$. Причина — у $z$ и $-z$ одинаковое отношение $\frac{y}{x}$, а $\operatorname{arctg}$ принимает значения только в $(-\frac{\pi}{2}, \frac{\pi}{2})$, то есть в правой полуплоскости. Формула верна лишь при $x > 0$; при $x < 0$ к ней нужно прибавить или вычесть $\pi$, при $x = 0$ она не определена. Надёжнее находить $\varphi$ по паре $\cos \varphi = \frac{x}{r}$, $\sin \varphi = \frac{y}{r}$, сначала определив четверть по знакам $x$ и $y$.
:::

::: {.remark #rem:lec11:not-trig tag="подводный камень"}
Не всякая запись с косинусом и синусом — тригонометрическая форма. Число $1 - i\sqrt3$ из примера [-@ex:lec11:trig-forms] хочется записать как $2(\cos \frac{\pi}{3} - i \sin \frac{\pi}{3})$, вынеся минус из синуса, — значение верное, но угол $\frac{\pi}{3}$ к этому числу отношения не имеет, и формулами умножения, Муавра и корней такой записью пользоваться нельзя. В $-2(\cos \frac{\pi}{3} + i \sin \frac{\pi}{3})$ множитель отрицателен, и $2$ — модуль, а $\frac{\pi}{3}$ — **не** аргумент: число равно $-1 - i\sqrt3$, его аргумент $-\frac{2\pi}{3}$. В $\cos \varphi - i \sin \varphi$ перед синусом минус: это $\cos(-\varphi) + i \sin(-\varphi)$, аргумент $-\varphi$. В $\sin \varphi + i \cos \varphi$ функции переставлены: это $\cos(\frac{\pi}{2} - \varphi) + i \sin(\frac{\pi}{2} - \varphi)$. Прежде чем читать модуль и аргумент из записи, её приводят к виду [-@eq:lec11:trig] с $r > 0$, одним и тем же углом и знаком «$+$».
:::

## Умножение и деление в тригонометрической форме {#sec:lec11:mult}

::: {.theorem #thm:lec11:trig-mult title="умножение и деление в тригонометрической форме"}
Пусть $z_1 = r_1(\cos \varphi_1 + i \sin \varphi_1)$, $z_2 = r_2(\cos \varphi_2 + i \sin \varphi_2)$. Тогда
$$z_1 z_2 = r_1 r_2 \big(\cos(\varphi_1 + \varphi_2) + i \sin(\varphi_1 + \varphi_2)\big), \qquad \frac{z_1}{z_2} = \frac{r_1}{r_2} \big(\cos(\varphi_1 - \varphi_2) + i \sin(\varphi_1 - \varphi_2)\big).$$ {#eq:lec11:trig-mult}
Иначе говоря, $|z_1 z_2| = |z_1| \, |z_2|$, $\left|\frac{z_1}{z_2}\right| = \frac{|z_1|}{|z_2|}$, а аргументы при умножении складываются и при делении вычитаются.
:::

::: proof
Раскроем скобки (теперь это законно по утверждению [-@prop:lec11:field]) и применим формулы косинуса и синуса суммы:
$$\begin{aligned} z_1 z_2 &= r_1 r_2 \big( (\cos \varphi_1 \cos \varphi_2 - \sin \varphi_1 \sin \varphi_2) + i (\cos \varphi_1 \sin \varphi_2 + \sin \varphi_1 \cos \varphi_2) \big) \\ &= r_1 r_2 \big( \cos(\varphi_1 + \varphi_2) + i \sin(\varphi_1 + \varphi_2) \big). \end{aligned}$$
Для частного обозначим через $w$ правую часть второй формулы. По уже доказанному $z_2 w = r_2 \cdot \frac{r_1}{r_2} \big(\cos(\varphi_2 + \varphi_1 - \varphi_2) + i \sin(\varphi_2 + \varphi_1 - \varphi_2)\big) = z_1$. Умножив обе части равенства $z_2 w = z_1$ на $z_2^{-1}$ (утверждение [-@prop:lec11:complex-division]), получаем $w = z_1 z_2^{-1} = \frac{z_1}{z_2}$.
:::

*Геометрический смысл.* Умножение на $z_2 = r_2(\cos \varphi_2 + i \sin \varphi_2)$ поворачивает каждую точку плоскости вокруг нуля на угол $\varphi_2$ и растягивает в $r_2$ раз (рис. [-@fig:lec11:product]). Умножение на $i$ — поворот на $\frac{\pi}{2}$ без растяжения: $i(x + iy) = -y + ix$. Отсюда ещё одно объяснение равенства $i^2 = -1$: два поворота на прямой угол — поворот на $\pi$, то есть смена знака.

::: {.example #ex:lec11:product}
Перемножим $z_1 = 1 + i\sqrt3$ и $z_2 = 1 + i$ в обеих формах.

$z_1 = 2(\cos \frac{\pi}{3} + i \sin \frac{\pi}{3})$ (пример [-@ex:lec11:trig-forms]), $z_2 = \sqrt2(\cos \frac{\pi}{4} + i \sin \frac{\pi}{4})$. По теореме [-@thm:lec11:trig-mult] модуль произведения $2\sqrt2$, аргумент $\frac{\pi}{3} + \frac{\pi}{4} = \frac{7\pi}{12}$. В алгебраической форме $(1 + i\sqrt3)(1 + i) = 1 + i + i\sqrt3 + i^2\sqrt3 = (1 - \sqrt3) + i(1 + \sqrt3)$. Проверка модуля: $(1 - \sqrt3)^2 + (1 + \sqrt3)^2 = 2 + 2 \cdot 3 = 8 = (2\sqrt2)^2$. Попутно получилось значение, которого нет в школьной таблице: $\cos \frac{7\pi}{12} = \frac{1 - \sqrt3}{2\sqrt2} = \frac{\sqrt2 - \sqrt6}{4}$.
:::

::: {.remark #rem:lec11:arg-sum-trap tag="подводный камень"}
Аргументы складываются как множества: $\operatorname{Arg}(z_1 z_2) = \{ \alpha + \beta : \alpha \in \operatorname{Arg} z_1, \; \beta \in \operatorname{Arg} z_2 \}$. Для главных значений равенство $\arg(z_1 z_2) = \arg z_1 + \arg z_2$ может не выполняться: сумма может выйти за $(-\pi, \pi]$. Например, $z_1 = z_2 = -1 + i$, $\arg z_1 = \frac{3\pi}{4}$, сумма аргументов $\frac{3\pi}{2}$, а $(-1 + i)^2 = 1 - 2i + i^2 = -2i$ и $\arg(-2i) = -\frac{\pi}{2} = \frac{3\pi}{2} - 2\pi$. После сложения аргументов главное значение находят, вычитая или прибавляя $2\pi$.
:::

Частные случаи: $z^{-1} = \frac{1}{r}\big(\cos(-\varphi) + i \sin(-\varphi)\big)$ (так как $1 = 1 \cdot (\cos 0 + i \sin 0)$), $\bar z = r\big(\cos(-\varphi) + i \sin(-\varphi)\big)$. Обратное и сопряжённое имеют противоположный аргумент, и $z^{-1} = \frac{\bar z}{|z|^2}$ — та же формула, что в утверждении [-@prop:lec11:complex-division].

## Формула Муавра {#sec:lec11:moivre}

::: {.theorem #thm:lec11:moivre title="формула Муавра"}
Если $z = r(\cos \varphi + i \sin \varphi)$, то для любого $n \in \N$
$$z^n = r^n (\cos n\varphi + i \sin n\varphi).$$ {#eq:lec11:moivre}
:::

::: proof
Индукция по $n$. При $n = 1$ это запись $z$. Пусть формула верна для $n = k$. Тогда по теореме [-@thm:lec11:trig-mult]
$$z^{k+1} = z^k \cdot z = r^k r \big(\cos(k\varphi + \varphi) + i \sin(k\varphi + \varphi)\big) = r^{k+1}\big(\cos (k+1)\varphi + i \sin (k+1)\varphi\big).$$
По принципу математической индукции формула верна при всех $n \in \N$.
:::

При $z \ne 0$ формула верна и для целых $n \le 0$, если положить $z^0 = 1$ и $z^{-n} = (z^{-1})^n$: число $z^{-1}$ имеет модуль $r^{-1}$ и аргумент $-\varphi$, и $(z^{-1})^n = r^{-n}\big(\cos(-n\varphi) + i \sin(-n\varphi)\big)$.

::: {.example #ex:lec11:moivre}
Вычислим $(1 + i\sqrt3)^{20}$.

$1 + i\sqrt3 = 2(\cos \frac{\pi}{3} + i \sin \frac{\pi}{3})$, поэтому $(1 + i\sqrt3)^{20} = 2^{20} (\cos \frac{20\pi}{3} + i \sin \frac{20\pi}{3})$. Угол $\frac{20\pi}{3} = 6\pi + \frac{2\pi}{3}$, $\cos \frac{2\pi}{3} = -\frac12$, $\sin \frac{2\pi}{3} = \frac{\sqrt3}{2}$, откуда $2^{20}(-\frac12 + \frac{\sqrt3}{2} i) = -2^{19} + 2^{19}\sqrt3 \, i$. Проверка на маленькой степени: по формуле $(1 + i\sqrt3)^3 = 8 (\cos \pi + i \sin \pi) = -8$; напрямую $(1 + i\sqrt3)^2 = 1 + 2i\sqrt3 - 3 = -2 + 2i\sqrt3$ и $(-2 + 2i\sqrt3)(1 + i\sqrt3) = -2 - 2i\sqrt3 + 2i\sqrt3 + 2 \cdot 3 \, i^2 = -8$. Значит, $(1 + i\sqrt3)^{20} = (-8)^6 (1 + i\sqrt3)^2 = 2^{18}(-2 + 2i\sqrt3)$ — то же самое.
:::

*Формулы кратных углов.* Если $|z| = 1$, формула Муавра даёт $(\cos \varphi + i \sin \varphi)^n = \cos n\varphi + i \sin n\varphi$. Левую часть можно раскрыть по биному Ньютона (он верен в $\mathbb{C}$, замечание [-@rem:lec11:field]), а затем приравнять действительные и мнимые части. Обозначим $c = \cos \varphi$, $s = \sin \varphi$. При $n = 3$:
$$(c + is)^3 = c^3 + 3c^2 (is) + 3c (is)^2 + (is)^3 = (c^3 - 3cs^2) + i(3c^2 s - s^3),$$
откуда, с учётом $s^2 = 1 - c^2$ и $c^2 = 1 - s^2$,
$$\cos 3\varphi = c^3 - 3cs^2 = 4\cos^3 \varphi - 3\cos \varphi, \qquad \sin 3\varphi = 3c^2 s - s^3 = 3\sin \varphi - 4\sin^3 \varphi.$$ {#eq:lec11:triple}
Проверка при $\varphi = \frac{\pi}{3}$: $\cos \pi = -1$ и $4 \cdot \frac18 - \frac32 = -1$.

## Корни $n$-й степени {#sec:lec11:roots}

В $\R$ у уравнения $x^3 = 8$ один корень, у $x^2 = 4$ — два, у $x^2 = -4$ — ни одного. В $\mathbb{C}$ картина единообразная.

::: {.definition #def:lec11:root title="корень $n$-й степени"}
Пусть $w \in \mathbb{C}$, $n \in \N$. *Корнем $n$-й степени* из $w$ называется любое $z \in \mathbb{C}$, для которого $z^n = w$. Множество всех таких $z$ обозначается $\sqrt[n]{w}$.
:::

::: {.theorem #thm:lec11:roots title="о корнях $n$-й степени"}
Пусть $w = \rho(\cos \psi + i \sin \psi) \ne 0$ и $n \in \N$. Тогда у $w$ ровно $n$ различных корней $n$-й степени:
$$z_k = \sqrt[n]{\rho} \left( \cos \frac{\psi + 2\pi k}{n} + i \sin \frac{\psi + 2\pi k}{n} \right), \qquad k = 0, 1, \dots, n - 1,$$ {#eq:lec11:roots}
где $\sqrt[n]{\rho}$ — арифметический корень из положительного числа $\rho$.
:::

::: proof
*Идея:* записать искомое $z$ в тригонометрической форме, применить формулу Муавра и приравнять модули и аргументы по [-@eq:lec11:trig-equal].

Корень $z$ не равен нулю, так как $0^n = 0 \ne w$. Пусть $z = r(\cos \varphi + i \sin \varphi)$, $r > 0$. По формуле Муавра $z^n = r^n(\cos n\varphi + i \sin n\varphi)$, и по [-@eq:lec11:trig-equal] равенство $z^n = w$ означает
$$r^n = \rho, \qquad n\varphi = \psi + 2\pi k, \quad k \in \Z.$$
Положительное $r$ с $r^n = \rho$ одно — $r = \sqrt[n]{\rho}$, а $\varphi = \frac{\psi + 2\pi k}{n}$. Итак, корни — это числа $z_k$ из [-@eq:lec11:roots] при всех $k \in \Z$, и остаётся понять, какие из них совпадают.

По [-@eq:lec11:trig-equal] $z_k = z_m$ тогда и только тогда, когда $\frac{\psi + 2\pi k}{n} - \frac{\psi + 2\pi m}{n} = \frac{2\pi (k - m)}{n}$ кратно $2\pi$, то есть $k - m$ делится на $n$. Любое целое $k$ отличается от своего остатка при делении на $n$ на кратное $n$, поэтому каждый корень совпадает с одним из $z_0, \dots, z_{n-1}$. А при $0 \le m < k \le n - 1$ разность $k - m$ лежит между $1$ и $n - 1$ и на $n$ не делится, поэтому $z_0, \dots, z_{n-1}$ попарно различны.
:::

*Геометрия.* Все корни имеют модуль $\sqrt[n]{\rho}$ и лежат на окружности этого радиуса. Аргумент первого, $z_0$, равен $\frac{\psi}{n}$, а каждый следующий получается из предыдущего поворотом на $\frac{2\pi}{n}$. Значит, при $n \ge 3$ корни — вершины правильного $n$-угольника, вписанного в окружность радиуса $\sqrt[n]{\rho}$ (рис. [-@fig:lec11:roots]); при $n = 2$ — две противоположные точки $\pm z_0$.

::: {.example #ex:lec11:cube-roots}

$8i = 8(\cos \frac{\pi}{2} + i \sin \frac{\pi}{2})$, $\rho = 8$, $\psi = \frac{\pi}{2}$. По [-@eq:lec11:roots] $z_k = 2\big(\cos(\frac{\pi}{6} + \frac{2\pi k}{3}) + i \sin(\frac{\pi}{6} + \frac{2\pi k}{3})\big)$: при $k = 0$ угол $\frac{\pi}{6}$, $z_0 = 2(\frac{\sqrt3}{2} + \frac{i}{2}) = \sqrt3 + i$; при $k = 1$ угол $\frac{5\pi}{6}$, $z_1 = -\sqrt3 + i$; при $k = 2$ угол $\frac{3\pi}{2}$, $z_2 = -2i$. Проверка: $(-2i)^3 = -8i^3 = -8 \cdot (-i) = 8i$. Корни — вершины правильного треугольника на окружности радиуса $2$ (рис. [-@fig:lec11:roots]).
:::

::: {.remark #rem:lec11:root-notation tag="подводный камень"}
Знак $\sqrt[n]{\ }$ в $\R$ и в $\mathbb{C}$ означает разное. В $\R$ запись $\sqrt[3]{-8}$ — одно число $-2$, а $\sqrt{4}$ — одно неотрицательное число $2$. В $\mathbb{C}$ по определению [-@def:lec11:root] $\sqrt[3]{-8}$ — множество из трёх чисел: $-8 = 8(\cos \pi + i \sin \pi)$, корни имеют аргументы $\frac{\pi}{3}, \pi, \frac{5\pi}{3}$, то есть $\sqrt[3]{-8} = \{1 + i\sqrt3, \; -2, \; 1 - i\sqrt3\}$. Вещественный корень среди них есть, но он лишь один из трёх. Ответ «$\sqrt[3]{-8} = -2$» в задаче про $\mathbb{C}$ теряет два корня. Арифметический корень $\sqrt[n]{\rho}$ в формуле [-@eq:lec11:roots] — вещественный, из положительного числа, и он ровно один.
:::

::: {.remark #rem:lec11:roots-corner tag="корнер-кейс"}
При $w = 0$ теорема не применима: $\arg 0$ не определён. Корень один: $z^n = 0$ влечёт $|z|^n = 0$, то есть $z = 0$. При $n = 1$ формула [-@eq:lec11:roots] даёт единственный корень $z_0 = w$.
:::

*Корни из единицы.* При $w = 1$ ($\rho = 1$, $\psi = 0$) корни
$$\varepsilon_k = \cos \frac{2\pi k}{n} + i \sin \frac{2\pi k}{n}, \qquad k = 0, \dots, n - 1,$$
делят единичную окружность на $n$ равных дуг; $\varepsilon_0 = 1$. По формуле Муавра $\varepsilon_k = \varepsilon_1^k$. Например, корни 4-й степени из единицы — $1, i, -1, -i$. Если $z_0$ — один корень $n$-й степени из $w$, то все корни — $z_0 \varepsilon_0, z_0 \varepsilon_1, \dots, z_0 \varepsilon_{n-1}$: каждое из этих $n$ различных чисел — корень, так как $(z_0 \varepsilon_k)^n = w \cdot 1$, а больше $n$ корней нет. Так, корни $z^3 = 8i$ из примера [-@ex:lec11:cube-roots] получаются из $-2i$ поворотами на $\pm \frac{2\pi}{3}$.

::: {.example #ex:lec11:sixth-roots}
Найдём все корни шестой степени из единицы, то есть все корни уравнения $z^6 - 1 = 0$.

$1 = 1 \cdot (\cos 0 + i \sin 0)$, $\rho = 1$, $\psi = 0$. По [-@eq:lec11:roots] $z_k = \cos \frac{2\pi k}{6} + i \sin \frac{2\pi k}{6} = \cos \frac{\pi k}{3} + i \sin \frac{\pi k}{3}$, $k = 0, \dots, 5$. Первый корень $z_0 = 1$, шаг $\frac{\pi}{3}$, корни — вершины правильного шестиугольника, вписанного в единичную окружность:
$$z_0 = 1, \quad z_1 = \tfrac12 + \tfrac{\sqrt3}{2} i, \quad z_2 = -\tfrac12 + \tfrac{\sqrt3}{2} i, \quad z_3 = -1, \quad z_4 = -\tfrac12 - \tfrac{\sqrt3}{2} i, \quad z_5 = \tfrac12 - \tfrac{\sqrt3}{2} i.$$
Для $z_4$ и $z_5$ взяты главные значения аргумента $-\frac{2\pi}{3}$ и $-\frac{\pi}{3}$. Проверка по формуле Муавра: $z_1^6 = \cos 2\pi + i \sin 2\pi = 1$. В $\R$ корней только два, $\pm 1$. Остальные четыре разбились на пары сопряжённых: $z_5 = \bar z_1$, $z_4 = \bar z_2$. Это не случайно: так устроены корни любого многочлена с вещественными коэффициентами (лекция 12).
:::

*Квадратный корень двумя способами.* В задаче [-@prob:lec10:sqrt] уравнение $z^2 = -3 + 4i$ решено в алгебраической форме, системой для $\operatorname{Re} z$, $\operatorname{Im} z$; ответ $\pm(1 + 2i)$. По теореме [-@thm:lec11:roots]: $\rho = 5$, $\cos \psi = -\frac35$, $\sin \psi = \frac45$, и $z = \pm\sqrt5 (\cos \frac{\psi}{2} + i \sin \frac{\psi}{2})$. Угол $\psi$ не табличный, но половинный находится по формулам понижения степени: $\psi \in (\frac{\pi}{2}, \pi)$, поэтому $\frac{\psi}{2}$ в первой четверти и $\cos \frac{\psi}{2} = \sqrt{\frac{1 + \cos \psi}{2}} = \frac{1}{\sqrt5}$, $\sin \frac{\psi}{2} = \sqrt{\frac{1 - \cos \psi}{2}} = \frac{2}{\sqrt5}$. Получаем $z = \pm(1 + 2i)$ — то же. Какой способ выбирать:

| Задача | Способ |
| --- | --- |
| $z^2 = w$, аргумент $w$ не табличный | алгебраический: система $x^2 - y^2 = \operatorname{Re} w$, $2xy = \operatorname{Im} w$ |
| $z^n = w$, $n \ge 3$ | тригонометрический, формула [-@eq:lec11:roots] |
| $z^n = w$, аргумент $w$ табличный | тригонометрический: ответ сразу и вместе с картинкой |

## Формула Эйлера {#sec:lec11:euler}

Теорема [-@thm:lec11:trig-mult] и формула Муавра говорят, что функция $\varphi \mapsto \cos \varphi + i \sin \varphi$ превращает сложение углов в умножение: значение на сумме углов равно произведению значений, на $n\varphi$ — $n$-й степени. Так ведёт себя показательная функция: $a^{x_1} a^{x_2} = a^{x_1 + x_2}$, $(a^x)^n = a^{nx}$. Это объясняет обозначение.

::: {.definition #def:lec11:euler title="формула Эйлера"}
Для вещественного $\varphi$ полагают
$$e^{i\varphi} := \cos \varphi + i \sin \varphi.$$ {#eq:lec11:euler}
Запись $z = r e^{i\varphi}$, где $r = |z| > 0$, $\varphi \in \operatorname{Arg} z$, называется *показательной формой* комплексного числа $z \ne 0$.
:::

В показательной форме теорема [-@thm:lec11:trig-mult] и формула Муавра выглядят как обычные правила действий со степенями:
$$r_1 e^{i\varphi_1} \cdot r_2 e^{i\varphi_2} = r_1 r_2 \, e^{i(\varphi_1 + \varphi_2)}, \qquad \frac{r_1 e^{i\varphi_1}}{r_2 e^{i\varphi_2}} = \frac{r_1}{r_2} \, e^{i(\varphi_1 - \varphi_2)}, \qquad (r e^{i\varphi})^n = r^n e^{in\varphi}.$$
Число $e$ здесь не случайно: в матанализе $e^{i\varphi}$ определяют через степенной ряд экспоненты, и равенство [-@eq:lec11:euler] становится теоремой. В нашем курсе это определение. Самый известный частный случай — *тождество Эйлера* $e^{i\pi} + 1 = 0$, связывающее $0$, $1$, $e$, $\pi$ и $i$. Ещё примеры: $e^{i\pi/2} = i$, $e^{2\pi i} = 1$, $1 + i\sqrt3 = 2 e^{i\pi/3}$.

::: {.remark #rem:lec11:periodic tag="корнер-кейс"}
У вещественной экспоненты из $e^{x_1} = e^{x_2}$ следует $x_1 = x_2$. У $e^{i\varphi}$ так нельзя: $e^{2\pi i} = e^{0} = 1$, хотя $2\pi \ne 0$. По [-@eq:lec11:trig-equal] $e^{i\varphi_1} = e^{i\varphi_2}$ тогда и только тогда, когда $\varphi_1 - \varphi_2 = 2\pi k$, $k \in \Z$: функция $e^{i\varphi}$ периодична с периодом $2\pi$. Поэтому при решении уравнений в показательной форме к аргументу добавляют $2\pi k$ — ровно это и дало $n$ корней в теореме [-@thm:lec11:roots]. И ещё: $|e^{i\varphi}| = 1$ при любом вещественном $\varphi$, все такие числа лежат на единичной окружности.
:::

::: {.corollary #cor:lec11:euler-cos-sin title="косинус и синус через экспоненту"}
Для любого вещественного $\varphi$
$$\cos \varphi = \frac{e^{i\varphi} + e^{-i\varphi}}{2}, \qquad \sin \varphi = \frac{e^{i\varphi} - e^{-i\varphi}}{2i}.$$ {#eq:lec11:cos-sin}
:::

::: proof
$e^{-i\varphi} = \cos(-\varphi) + i \sin(-\varphi) = \cos \varphi - i \sin \varphi = \overline{e^{i\varphi}}$. Складывая с $e^{i\varphi} = \cos \varphi + i \sin \varphi$, получаем $2\cos \varphi$, вычитая — $2i \sin \varphi$. Это частный случай общих формул $\operatorname{Re} z = \frac{z + \bar z}{2}$ и $\operatorname{Im} z = \frac{z - \bar z}{2i}$ для $z = e^{i\varphi}$.
:::

Формулы кратных углов [-@eq:lec11:triple] выражают $\cos n\varphi$ через степени $\cos \varphi$. Формулы [-@eq:lec11:cos-sin] позволяют сделать обратное — *понизить степень* (линеаризовать), выразив $\cos^n \varphi$ через косинусы кратных углов. Это понадобится в матанализе при интегрировании.

::: {.example #ex:lec11:linearize}
Выразим $\cos^3 \varphi$ через $\cos \varphi$ и $\cos 3\varphi$.

Обозначим $u = e^{i\varphi}$; тогда $e^{-i\varphi} = u^{-1}$ и по биному
$$\begin{aligned} \cos^3 \varphi &= \left(\frac{u + u^{-1}}{2}\right)^3 = \frac{u^3 + 3u + 3u^{-1} + u^{-3}}{8} \\ &= \frac{(u^3 + u^{-3}) + 3(u + u^{-1})}{8} = \frac{2\cos 3\varphi + 6\cos \varphi}{8}. \end{aligned}$$
*Ключ:* после раскрытия скобок слагаемые группируются в пары $u^k + u^{-k} = 2\cos k\varphi$. Проверка: это та же формула [-@eq:lec11:triple], решённая относительно $\cos^3 \varphi$.

*Ответ:* $\cos^3 \varphi = \frac{3\cos \varphi + \cos 3\varphi}{4}$.
:::

## Комплексные многочлены. Основная теорема алгебры {#sec:lec11:polynomials}

Уравнение $z^n = w$, $w \ne 0$, имеет в $\mathbb{C}$ ровно $n$ корней, хотя в $\R$ у $x^6 = 1$ их только два, а у $x^6 = -1$ ни одного. Это частный случай общего факта о многочленах, ради которого комплексные числа и вводились (лекция 10): в $\mathbb{C}$ у любого многочлена положительной степени есть корень.

::: {.definition #def:lec11:polynomial title="многочлен, степень, корень"}
*Многочленом* (полиномом) с комплексными коэффициентами называется выражение
$$f(z) = a_n z^n + a_{n-1} z^{n-1} + \dots + a_1 z + a_0, \qquad a_0, \dots, a_n \in \mathbb{C}.$$
Многочлены равны, если равны их коэффициенты при одинаковых степенях. Если $a_n \ne 0$, то $n$ называется *степенью* многочлена, $\deg f = n$, а $a_n$ — *старшим коэффициентом*. Число $c \in \mathbb{C}$ называется *корнем* $f$, если $f(c) = 0$, то есть $c$ — решение уравнения $f(z) = 0$. Если все $a_k \in \R$, многочлен называется многочленом с вещественными коэффициентами (над $\R$); переменную тогда часто обозначают $x$.
:::

::: {.remark #rem:lec11:zero-poly tag="корнер-кейс"}
У нулевого многочлена $f = 0$ (все коэффициенты нулевые) старшего коэффициента нет, и степень ему не приписывают (иногда полагают $\deg 0 = -\infty$). Корнем нулевого многочлена является любое число. Многочлены степени $0$ — ненулевые константы — корней не имеют. Поэтому утверждения о корнях ниже — для многочленов степени $n \ge 1$.
:::

::: {.theorem #thm:lec11:fta title="«основная теорема алгебры»"}
Любой многочлен $f(z) = a_n z^n + \dots + a_1 z + a_0$ степени $n \ge 1$ ($a_n \ne 0$) с комплексными коэффициентами имеет комплексный корень: существует $z_0 \in \mathbb{C}$ с $f(z_0) = 0$.
:::

Без доказательства. Строгое доказательство опирается на теорию функций комплексного переменного, а не на алгебру. Название историческое, отсюда кавычки: с XVII века основной задачей алгебры считалось нахождение корней многочленов, доказать теорему пытались Декарт, Эйлер, Лагранж, Лаплас, а строго её доказал Гаусс в начале XIX века.

::: {.remark #rem:lec11:closed title="алгебраическая замкнутость"}
Теорема говорит, что множество $\mathbb{C}$ *алгебраически замкнуто*: у любого многочлена степени $n \ge 1$ с комплексными коэффициентами есть корень из того же множества. Для $\Q$ и $\R$ это неверно. У $x^2 - 2$ рациональные коэффициенты, а корни $\pm\sqrt2 \notin \Q$. У $x^2 + 1$ вещественные коэффициенты, а корни $\pm i \notin \R$. Условие $n \ge 1$ существенно: у константы $5$ корней нет (замечание [-@rem:lec11:zero-poly]).
:::

Из основной теоремы алгебры и теоремы Безу следует, что у многочлена степени $n$ ровно $n$ комплексных корней с учётом кратности: по теореме Безу корень позволяет поделить многочлен на $z - z_0$ без остатка, у частного снова есть корень, и так $n$ раз. Это — в лекции 12 (теорема [-@thm:lec12:bezout], следствие [-@cor:lec12:linear-factors]). Корни многочленов понадобятся и в модуле 4: собственные значения матрицы — корни её характеристического многочлена, и основная теорема алгебры гарантирует, что над $\mathbb{C}$ они всегда есть.

# Практика

::: {.problem #prob:lec11:arithmetic}
Найдите $\operatorname{Re} z$, $\operatorname{Im} z$ и $\bar z$ для $z = \dfrac{(1 + 2i)(3 - i)}{1 - i}$.
:::

::: solution
Числитель: $(1 + 2i)(3 - i) = 3 - i + 6i - 2i^2 = 5 + 5i$. *Ключ:* делим, умножая числитель и знаменатель на $\overline{1 - i} = 1 + i$:
$$z = \frac{(5 + 5i)(1 + i)}{(1 - i)(1 + i)} = \frac{5 + 5i + 5i + 5i^2}{1 + 1} = \frac{10i}{2} = 5i.$$
Проверка по определению частного: $(1 - i) \cdot 5i = 5i - 5i^2 = 5 + 5i$ — числитель. Мнимая часть — вещественное число $5$, а не $5i$ (замечание [-@rem:lec10:im-real]).

*Ответ:* $z = 5i$: $\operatorname{Re} z = 0$, $\operatorname{Im} z = 5$, $\bar z = -5i$.
:::

::: {.problem #prob:lec11:conj-equation}
Решите уравнение $(1 + i) z + 2 \bar z = 5 + i$.
:::

::: solution
*Ключ:* $\bar z$ не выражается через $z$ сложением и умножением, поэтому переходим к $x = \operatorname{Re} z$, $y = \operatorname{Im} z$ и приравниваем действительные и мнимые части. При $z = x + iy$: $(1 + i)(x + iy) = (x - y) + i(x + y)$, $2 \bar z = 2x - 2iy$. Уравнение принимает вид $(3x - y) + i(x - y) = 5 + i$, то есть
$$\begin{cases} 3x - y = 5, \\ x - y = 1. \end{cases}$$
Вычитая, $2x = 4$, $x = 2$, $y = 1$. Проверка: $(1 + i)(2 + i) = 2 + i + 2i + i^2 = 1 + 3i$, $2(2 - i) = 4 - 2i$, сумма $5 + i$.

*Ответ:* $z = 2 + i$.
:::

::: {.problem #prob:lec11:trig-form}
Запишите в тригонометрической и показательной форме числа $z_1 = -\sqrt3 + i$, $z_2 = -2 - 2i$, $z_3 = -4i$, $z_4 = -3\left(\cos \frac{\pi}{5} - i \sin \frac{\pi}{5}\right)$.
:::

::: solution
$z_1$: $r = \sqrt{3 + 1} = 2$, $\cos \varphi = -\frac{\sqrt3}{2}$, $\sin \varphi = \frac12$ — вторая четверть, $\varphi = \frac{5\pi}{6}$ (а не $\operatorname{arctg}(-\frac{1}{\sqrt3}) = -\frac{\pi}{6}$, замечание [-@rem:lec11:arctan-trap]). $z_2$: $r = \sqrt{8} = 2\sqrt2$, $\cos \varphi = \sin \varphi = -\frac{1}{\sqrt2}$ — третья четверть, $\varphi = -\frac{3\pi}{4}$. $z_3$ лежит на отрицательной мнимой полуоси: $r = 4$, $\varphi = -\frac{\pi}{2}$.

$z_4$: *ключ:* запись не тригонометрическая (замечание [-@rem:lec11:not-trig]) — множитель отрицателен и перед синусом минус. Раскроем: $z_4 = -3\cos \frac{\pi}{5} + 3i \sin \frac{\pi}{5}$. Нужен угол с косинусом $-\cos \frac{\pi}{5}$ и синусом $\sin \frac{\pi}{5}$; это $\pi - \frac{\pi}{5} = \frac{4\pi}{5}$ (формулы приведения). Модуль $3$.

*Ответ:* $z_1 = 2\left(\cos \frac{5\pi}{6} + i \sin \frac{5\pi}{6}\right) = 2e^{5\pi i/6}$; $z_2 = 2\sqrt2 \left(\cos\left(-\frac{3\pi}{4}\right) + i \sin\left(-\frac{3\pi}{4}\right)\right) = 2\sqrt2 \, e^{-3\pi i/4}$; $z_3 = 4\left(\cos\left(-\frac{\pi}{2}\right) + i \sin\left(-\frac{\pi}{2}\right)\right) = 4e^{-\pi i/2}$; $z_4 = 3\left(\cos \frac{4\pi}{5} + i \sin \frac{4\pi}{5}\right) = 3e^{4\pi i/5}$.
:::

::: {.problem #prob:lec11:power}
Вычислите $\dfrac{(1 - i)^{10}}{(\sqrt3 + i)^6}$.
:::

::: solution
*Ключ:* в тригонометрической форме степень и частное считаются по модулям и аргументам отдельно. $1 - i = \sqrt2 \, e^{-i\pi/4}$, $\sqrt3 + i = 2 e^{i\pi/6}$. По формуле Муавра $(1 - i)^{10} = 32 \, e^{-10\pi i/4} = 32 \, e^{-5\pi i/2}$, $(\sqrt3 + i)^6 = 64 \, e^{i\pi}$. Частное по теореме [-@thm:lec11:trig-mult]: $\frac{32}{64} e^{i(-5\pi/2 - \pi)} = \frac12 e^{-7\pi i/2}$. Угол $-\frac{7\pi}{2} = -4\pi + \frac{\pi}{2}$, поэтому ответ $\frac12 (\cos \frac{\pi}{2} + i \sin \frac{\pi}{2}) = \frac{i}{2}$. Проверка в алгебраической форме: $(1 - i)^2 = -2i$, $(1 - i)^{10} = (-2i)^5 = -32 i^5 = -32i$; $(\sqrt3 + i)^3 = 8 e^{i\pi/2} = 8i$, $(\sqrt3 + i)^6 = -64$; $\frac{-32i}{-64} = \frac{i}{2}$.

*Ответ:* $\dfrac{i}{2}$.
:::

::: {.problem #prob:lec11:fourth-roots}
Найдите все корни уравнения $z^4 = -8 + 8\sqrt3 \, i$ и опишите их расположение на комплексной плоскости.
:::

::: solution
$|w| = \sqrt{64 + 192} = 16$, $\cos \psi = -\frac{8}{16} = -\frac12$, $\sin \psi = \frac{8\sqrt3}{16} = \frac{\sqrt3}{2}$, $\psi = \frac{2\pi}{3}$. По теореме [-@thm:lec11:roots] $z_k = 2\left(\cos\left(\frac{\pi}{6} + \frac{\pi k}{2}\right) + i \sin\left(\frac{\pi}{6} + \frac{\pi k}{2}\right)\right)$, $k = 0, 1, 2, 3$. *Ключ:* $\sqrt[4]{16} = 2$ — арифметический корень, а угол делится на $4$ вместе с $2\pi k$: шаг $\frac{2\pi}{4} = \frac{\pi}{2}$. Углы $\frac{\pi}{6}, \frac{2\pi}{3}, \frac{7\pi}{6}, \frac{5\pi}{3}$ дают $\sqrt3 + i$, $-1 + i\sqrt3$, $-\sqrt3 - i$, $1 - i\sqrt3$. Каждый следующий корень — предыдущий, умноженный на $i$ (поворот на $\frac{\pi}{2}$), поэтому это квадрат. Проверка: $(\sqrt3 + i)^2 = 2 + 2\sqrt3 \, i$, $(2 + 2\sqrt3 \, i)^2 = 4 + 8\sqrt3 \, i - 12 = -8 + 8\sqrt3 \, i$.

*Ответ:* $\sqrt3 + i$, $\; -1 + i\sqrt3$, $\; -\sqrt3 - i$, $\; 1 - i\sqrt3$ — вершины квадрата, вписанного в окружность радиуса $2$.
:::

::: {.problem #prob:lec11:roots-arg}
Найдите корни уравнения $z^4 + \dfrac{2i}{1 - i\sqrt3} = 0$, для которых $0 < \arg z < \frac{\pi}{2}$. Изобразите на комплексной плоскости число $w = -\dfrac{2i}{1 - i\sqrt3}$ и все корни $\sqrt[4]{w}$.
:::

::: solution
Уравнение — это $z^4 = w$. *Ключ:* $w$ приводим к тригонометрической форме по частям, не переходя к алгебраической: модули делятся, аргументы вычитаются (теорема [-@thm:lec11:trig-mult]). $2i = 2\left(\cos \frac{\pi}{2} + i \sin \frac{\pi}{2}\right)$, $1 - i\sqrt3 = 2\left(\cos\left(-\frac{\pi}{3}\right) + i \sin\left(-\frac{\pi}{3}\right)\right)$, поэтому у частного модуль $1$ и аргумент $\frac{\pi}{2} + \frac{\pi}{3} = \frac{5\pi}{6}$. Минус — умножение на $-1 = \cos \pi + i \sin \pi$: аргумент $w$ равен $\frac{5\pi}{6} + \pi = \frac{11\pi}{6}$, главное значение $-\frac{\pi}{6}$. Итак, $w = \cos\left(-\frac{\pi}{6}\right) + i \sin\left(-\frac{\pi}{6}\right) = \frac{\sqrt3 - i}{2}$. Проверка: $\frac{2i}{1 - i\sqrt3} = \frac{2i(1 + i\sqrt3)}{4} = \frac{-\sqrt3 + i}{2}$.

По теореме [-@thm:lec11:roots] корни имеют модуль $1$ и аргументы $\varphi_k = \frac{-\pi/6 + 2\pi k}{4} = -\frac{\pi}{24} + \frac{\pi k}{2}$: при $k = 0, 1, 2, 3$ это $-\frac{\pi}{24}$, $\frac{11\pi}{24}$, $\frac{23\pi}{24}$, $\frac{35\pi}{24}$ (главное значение последнего $-\frac{13\pi}{24}$). В интервал $\left(0, \frac{\pi}{2}\right) = \left(0, \frac{12\pi}{24}\right)$ попадает только $\varphi_1$. Корни — вершины квадрата на единичной окружности, на той же окружности лежит и $w$ (рис. [-@fig:lec11:roots-arg]).

*Ответ:* $z = \cos \frac{11\pi}{24} + i \sin \frac{11\pi}{24}$.
:::

::: {.problem #prob:lec11:roots-quotient}
Найдите то значение $u$ корня $\sqrt[3]{(1 + i\sqrt3)^2}$, для которого число $\dfrac{u}{1 - i}$ имеет аргумент $-\frac{31\pi}{36}$, и модуль числа $\dfrac{u}{1 - i}$.
:::

::: solution
$1 + i\sqrt3 = 2\left(\cos \frac{\pi}{3} + i \sin \frac{\pi}{3}\right)$, по формуле Муавра $(1 + i\sqrt3)^2 = 4\left(\cos \frac{2\pi}{3} + i \sin \frac{2\pi}{3}\right)$. Корни третьей степени: $u_k = \sqrt[3]{4}\,(\cos \theta_k + i \sin \theta_k)$, $\theta_k = \frac{2\pi}{9} + \frac{2\pi k}{3}$, то есть $\theta_0 = \frac{2\pi}{9}$, $\theta_1 = \frac{8\pi}{9}$, $\theta_2 = \frac{14\pi}{9}$. Так как $1 - i = \sqrt2\left(\cos\left(-\frac{\pi}{4}\right) + i \sin\left(-\frac{\pi}{4}\right)\right)$, число $\frac{u_k}{1 - i}$ имеет аргумент $\theta_k + \frac{\pi}{4}$: $\frac{17\pi}{36}$, $\frac{41\pi}{36}$, $\frac{65\pi}{36}$. *Ключ:* «имеет аргумент $-\frac{31\pi}{36}$» значит, что $-\frac{31\pi}{36}$ — один из аргументов, то есть отличается от $\theta_k + \frac{\pi}{4}$ на кратное $2\pi$. Подходит только $k = 1$: $\frac{41\pi}{36} - 2\pi = -\frac{31\pi}{36}$; у двух других разности $\frac{48\pi}{36} = \frac{4\pi}{3}$ и $\frac{96\pi}{36} = \frac{8\pi}{3}$ не кратны $2\pi$. Модуль частного $\frac{\sqrt[3]{4}}{\sqrt2} = 2^{2/3 - 1/2} = 2^{1/6}$.

*Ответ:* $u = \sqrt[3]{4}\left(\cos \frac{8\pi}{9} + i \sin \frac{8\pi}{9}\right)$, $\left|\dfrac{u}{1 - i}\right| = \sqrt[6]{2}$.
:::

::: {.problem #prob:lec11:linear-system}
Решите систему уравнений
$$\begin{cases} (1 + i) z_1 + i z_2 = 1 + 2i, \\ 2 z_1 + (1 - i) z_2 = 5 - 3i. \end{cases}$$
:::

::: solution
*Ключ:* правило Крамера (теорема [-@thm:lec06:cramer]) выведено только из свойств сложения, умножения и деления, поэтому верно и для комплексных коэффициентов (замечание [-@rem:lec11:field]). Определитель системы
$$\Delta = \begin{vmatrix} 1 + i & i \\ 2 & 1 - i \end{vmatrix} = (1 + i)(1 - i) - 2i = 2 - 2i \ne 0,$$
и решение единственно. Определители с заменёнными столбцами:
$$\Delta_1 = \begin{vmatrix} 1 + 2i & i \\ 5 - 3i & 1 - i \end{vmatrix} = (3 + i) - (3 + 5i) = -4i, \qquad \Delta_2 = \begin{vmatrix} 1 + i & 1 + 2i \\ 2 & 5 - 3i \end{vmatrix} = (8 + 2i) - (2 + 4i) = 6 - 2i.$$
Делим, умножая на сопряжённое к знаменателю (утверждение [-@prop:lec11:complex-division]): $z_1 = \frac{-4i}{2 - 2i} = \frac{-4i(2 + 2i)}{8} = 1 - i$, $z_2 = \frac{6 - 2i}{2 - 2i} = \frac{(6 - 2i)(2 + 2i)}{8} = \frac{16 + 8i}{8} = 2 + i$. Проверка первого уравнения: $(1 + i)(1 - i) + i(2 + i) = 2 + 2i - 1 = 1 + 2i$; второго: $2(1 - i) + (1 - i)(2 + i) = 2 - 2i + 3 - i = 5 - 3i$.

Так тоже можно: методом Гаусса. Из первого уравнения, умноженного на $1 - i$, получаем $2 z_1 + (1 + i) z_2 = (1 + 2i)(1 - i) = 3 + i$; вычитаем из второго: $-2i z_2 = 2 - 4i$, $z_2 = \frac{2 - 4i}{-2i} = 2 + i$.

*Ответ:* $z_1 = 1 - i$, $z_2 = 2 + i$.
:::

::: {.problem #prob:lec11:quadratic}
Решите уравнение $z^2 - (3 - i) z + 4 = 0$.
:::

::: solution
По замечанию [-@rem:lec11:quadratic] работает школьная формула. Дискриминант $D = (3 - i)^2 - 16 = 9 - 6i - 1 - 16 = -8 - 6i$. *Ключ:* квадратный корень из $D$ с нетабличным аргументом ищем в алгебраической форме: $d = x + iy$, $x^2 - y^2 = -8$, $2xy = -6$. Из второго $y = -\frac{3}{x}$, подстановка: $x^4 + 8x^2 - 9 = 0$, $(x^2 + 9)(x^2 - 1) = 0$, вещественное $x = \pm 1$, $d = \pm(1 - 3i)$. Корни: $\frac{(3 - i) + (1 - 3i)}{2} = 2 - 2i$ и $\frac{(3 - i) - (1 - 3i)}{2} = 1 + i$. Проверка: сумма корней $3 - i$, произведение $(2 - 2i)(1 + i) = 2 + 2i - 2i - 2i^2 = 4$ — коэффициенты уравнения с нужными знаками.

*Ответ:* $z = 2 - 2i$ и $z = 1 + i$.
:::

::: {.problem #prob:lec11:sin-cube}
Выразите $\sin^3 \varphi$ через $\sin \varphi$ и $\sin 3\varphi$.
:::

::: solution
По [-@eq:lec11:cos-sin] при $u = e^{i\varphi}$: $\sin^3 \varphi = \dfrac{(u - u^{-1})^3}{(2i)^3}$. Числитель по биному: $u^3 - 3u + 3u^{-1} - u^{-3} = (u^3 - u^{-3}) - 3(u - u^{-1}) = 2i \sin 3\varphi - 6i \sin \varphi$. *Ключ:* $(2i)^3 = 8i^3 = -8i$ — не забыть, что $i^3 = -i$. Итого $\sin^3 \varphi = \dfrac{2i \sin 3\varphi - 6i \sin \varphi}{-8i} = \dfrac{3\sin \varphi - \sin 3\varphi}{4}$. Проверка при $\varphi = \frac{\pi}{2}$: слева $1$, справа $\frac{3 - (-1)}{4} = 1$.

*Ответ:* $\sin^3 \varphi = \dfrac{3\sin \varphi - \sin 3\varphi}{4}$.
:::

# Итоги

- Сложение и умножение в $\mathbb{C}$ обладают девятью свойствами числового поля, как в $\R$. Поэтому в $\mathbb{C}$ верны бином Ньютона и формула корней квадратного уравнения, но сравнивать числа знаками $<$, $>$ нельзя.
- Сопряжение меняет знак мнимой части; $z \bar z = |z|^2$ вещественно, поэтому делят, умножая числитель и знаменатель на сопряжённое знаменателю: $z^{-1} = \frac{\bar z}{|z|^2}$.
- Ненулевое число однозначно задаётся модулем $r > 0$ и аргументом $\varphi$, определённым с точностью до $2\pi k$; аргумент находят по знакам $\cos \varphi = \frac{x}{r}$ и $\sin \varphi = \frac{y}{r}$, а не одним арктангенсом.
- При умножении модули перемножаются, а аргументы складываются: умножение на $r e^{i\varphi}$ — поворот на $\varphi$ с растяжением в $r$ раз; отсюда формула Муавра $(r e^{i\varphi})^n = r^n e^{in\varphi}$.
- У ненулевого $w$ ровно $n$ различных корней $n$-й степени; они лежат в вершинах правильного $n$-угольника, вписанного в окружность радиуса $\sqrt[n]{|w|}$, и в $\mathbb{C}$ знак $\sqrt[n]{w}$ обозначает множество из $n$ чисел.
- Формулы $\cos \varphi = \frac{e^{i\varphi} + e^{-i\varphi}}{2}$, $\sin \varphi = \frac{e^{i\varphi} - e^{-i\varphi}}{2i}$ вместе с формулой Муавра переводят степени синуса и косинуса в функции кратных углов и обратно.
- У любого многочлена положительной степени с комплексными коэффициентами есть комплексный корень; для $\Q$ и $\R$ это неверно.
