# Контекст

В лекции 9 доказано, что у однородной системы $Ax = 0$ с $\operatorname{Rg} A = r < n$ есть фундаментальная система решений — $n - r$ независимых решений (теорема [-@thm:lec09:fsr-existence]), и выведен критерий существования ненулевого решения квадратной однородной системы (следствие [-@cor:lec09:nonzero-solution]). Сегодня докажем, что ФСР описывает *все* решения: любое решение однородной системы — линейная комбинация столбцов ФСР. Затем опишем все решения неоднородной системы $Ax = b$: одно её решение плюс общее решение однородной — и разберём пример. На этом теория СЛАУ закончена. Во второй части лекции расширим $\R$ до комплексных чисел: определим их как пары вещественных чисел с особым умножением и выведем алгебраическую форму $x + iy$.

# После прочтения ты сможешь

- доказывать теорему о структуре общего решения однородной системы и выводить из неё, что независимых решений не больше $n - r$;
- записывать общее решение однородной системы через ФСР и раскладывать данное решение по данной ФСР;
- находить общее решение неоднородной системы в виде «частное решение плюс комбинация ФСР», в том числе при параметре, и сверять два ответа разного вида;
- составлять однородную систему, для которой данные столбцы образуют ФСР;
- переходить от пары $(x, y)$ к алгебраической форме $x + iy$, складывать и умножать комплексные числа, находить действительную и мнимую части;
- решать уравнения вида $z^2 = w$, сводя их к системе для действительной и мнимой частей.

# Теория

## Структура общего решения однородной СЛАУ {#sec:lec10:homogeneous}

ФСР — это $n - r$ независимых решений (определение [-@def:lec09:fsr]), и любые их линейные комбинации — тоже решения (свойство 1, утверждение [-@prop:lec08:solution-properties]). Покажем, что других решений нет: всё множество решений «натянуто» на ФСР, как на каркас.

::: {.theorem #thm:lec10:homogeneous title="о структуре общего решения однородной СЛАУ"}
Пусть $A \in M_{m \times n}(\R)$, $r = \operatorname{Rg} A < n$, и $\Phi_1, \dots, \Phi_k$, $k = n - r$, — ФСР системы $Ax = 0$. Тогда любое решение $x$ этой системы представляется в виде
$$x = c_1 \Phi_1 + \dots + c_k \Phi_k$$ {#eq:lec10:general-homogeneous}
с некоторыми числами $c_1, \dots, c_k \in \R$. Иначе говоря, любое решение — линейная комбинация столбцов ФСР. Обратно, при любых $c_1, \dots, c_k$ столбец [-@eq:lec10:general-homogeneous] — решение.
:::

::: proof
*Идея:* составим матрицу $D$ из столбца $x$ и столбцов ФСР и докажем, что её ранг равен $k$. Тогда столбцы ФСР — базисные, и $x$ выражается через них по теореме о базисном миноре.

Обратное утверждение — свойство 1 решений (утверждение [-@prop:lec08:solution-properties]). Докажем прямое. Если $r = 0$, то $A = O$, $k = n$; у матрицы $D$ ниже всего $n = k$ строк, поэтому в шаге 2 оценка $\operatorname{Rg} D \le k$ получается сразу из числа строк без шага 1, а оценка $\operatorname{Rg} D \ge k$ и шаг 3 проходят без изменений. Пусть $r \ge 1$ и, как в доказательстве теоремы [-@thm:lec09:fsr-existence], базисный минор $M$ матрицы $A$ стоит в левом верхнем углу (перенумерация неизвестных переставляет строки $D$, а перестановка строк ранг не меняет, теорема [-@thm:lec07:elementary]).

*Шаг 1: приведённая СЛАУ.* Как показано при доказательстве теоремы [-@thm:lec09:fsr-existence], система $Ax = 0$ равносильна системе [-@eq:lec09:principal]: слева главные переменные $x_1, \dots, x_r$ с матрицей $B$ базисного минора, справа — выражение от свободных. Матрица $B$ квадратная и невырожденная ($\det B = M \ne 0$), поэтому систему можно решить относительно главных переменных при любых значениях свободных: по правилу Крамера, методом Гаусса или как матричное уравнение, умножив слева на $B^{-1}$. Правая часть этой системы — $-C y$, где $y = (x_{r+1}, \dots, x_n)^T$ — столбец свободных переменных, а $C$ — матрица из коэффициентов $a_{ij}$ при них ($i \le r$, $j > r$). Значит, $(x_1, \dots, x_r)^T = -B^{-1} C y$, и каждая главная переменная — линейная комбинация свободных с коэффициентами, не зависящими от решения:
$$x_i = \alpha_{i,r+1} x_{r+1} + \dots + \alpha_{in} x_n, \qquad i = 1, \dots, r.$$ {#eq:lec10:main-via-free}
Система [-@eq:lec10:main-via-free], в которой главные переменные выражены через свободные, называется *приведённой*. Её решения — те же, что у $Ax = 0$.

*Шаг 2: матрица $D$.* Пусть $x$ — решение. Составим из столбцов $x, \Phi_1, \dots, \Phi_k$ вспомогательную матрицу $D = (x \; \Phi_1 \; \dots \; \Phi_k)$ размера $n \times (k + 1)$; её строки обозначим $D_1, \dots, D_n$ (в строке $D_i$ записаны $i$-е компоненты всех столбцов). Докажем, что $\operatorname{Rg} D = k$.

*$\operatorname{Rg} D \ge k$.* Столбцы $\Phi_1, \dots, \Phi_k$ линейно независимы, а ранг — наибольшее число линейно независимых столбцов (теорема [-@thm:lec08:rank]).

*$\operatorname{Rg} D \le k$.* Все столбцы $D$ — решения, поэтому каждый удовлетворяет приведённой системе [-@eq:lec10:main-via-free] с одними и теми же $\alpha_{ij}$. Подставив столбцы в первое уравнение, получаем, что первые компоненты всех столбцов выражаются через их компоненты с номерами $r + 1, \dots, n$ с одними и теми же коэффициентами, то есть $D_1 = \alpha_{1,r+1} D_{r+1} + \dots + \alpha_{1n} D_n$. Так же из $i$-го уравнения
$$D_i = \alpha_{i,r+1} D_{r+1} + \dots + \alpha_{in} D_n, \qquad i = 1, \dots, r.$$
Вычтем из каждой строки $D_i$, $i \le r$, эту комбинацию — это элементарные преобразования третьего типа, строки $D_{r+1}, \dots, D_n$ при этом не меняются. Получится матрица $D'$, у которой первые $r$ строк нулевые, а ненулевых строк не больше $n - r = k$. Любой минор $D'$ порядка больше $k$ захватывает нулевую строку и равен нулю (утверждение [-@prop:lec04:zero]), поэтому $\operatorname{Rg} D' \le k$. При элементарных преобразованиях ранг не меняется (теорема [-@thm:lec07:elementary]), значит, $\operatorname{Rg} D = \operatorname{Rg} D' \le k$.

*Шаг 3.* Итак, $\operatorname{Rg} D = k$. Матрица $(\Phi_1 \; \dots \; \Phi_k)$ имеет ранг $k$ (теорема [-@thm:lec08:rank]), то есть ненулевой минор порядка $k$. Это минор и матрицы $D$, и его порядок равен $\operatorname{Rg} D$, поэтому он базисный, а столбцы $\Phi_1, \dots, \Phi_k$ — базисные столбцы $D$. По теореме о базисном миноре (теорема [-@thm:lec07:basis-minor], п. 2) небазисный столбец $x$ — их линейная комбинация: существуют $c_1, \dots, c_k$ с $x = c_1 \Phi_1 + \dots + c_k \Phi_k$.
:::

::: {.definition #def:lec10:general-homogeneous title="общее решение однородной СЛАУ"}
Запись [-@eq:lec10:general-homogeneous], где $\Phi_1, \dots, \Phi_k$ — ФСР, а $c_1, \dots, c_k$ — произвольные числа, называется *общим решением* однородной системы $Ax = 0$ (в векторной форме). По теореме [-@thm:lec10:homogeneous] она описывает все решения и только их.
:::

Это та же идея, что в лекции 3 (определение [-@def:lec03:main-free]): общее решение — формула, которая при разных значениях параметров даёт все решения. Раньше параметрами были свободные переменные, теперь — коэффициенты $c_j$. Для *нормальной* ФСР это одно и то же: в строке $j$-й свободной переменной единица стоит только у $\Phi_j$, поэтому $c_j$ равен значению $j$-й свободной переменной. Например, для системы из примера [-@ex:lec09:fsr] с нормальной ФСР $\Phi_1 = (-9, 3, 1, 0)^T$, $\Phi_2 = (-7, 4, 0, 1)^T$ у решения $x = (-30, 15, 1, 3)^T$ свободные $x_3 = 1$, $x_4 = 3$, откуда $x = 1 \cdot \Phi_1 + 3 \cdot \Phi_2$. Для ненормальной ФСР коэффициенты находят из системы $c_1 \Phi_1 + \dots + c_k \Phi_k = x$, и достаточно сравнить компоненты свободных переменных: главные по ним определяются однозначно (формулы [-@eq:lec10:main-via-free]).

::: {.corollary #cor:lec10:max-independent title="о числе независимых решений"}
Пусть $r = \operatorname{Rg} A$. Любые $s > n - r$ решений однородной системы $Ax = 0$ линейно зависимы. Поэтому ФСР — это максимальный набор независимых решений: добавление к ФСР любого решения делает набор зависимым.
:::

::: proof
При $r = n$ единственное решение нулевое (замечание [-@rem:lec09:fsr-corner]), поэтому матрица $D$ из $s \ge 1$ решений нулевая и $\operatorname{Rg} D = 0 < s$. При $r < n$ в доказательстве оценки $\operatorname{Rg} D \le k$ (теорема [-@thm:lec10:homogeneous]) использовалось только то, что все столбцы $D$ — решения. В обоих случаях матрица из $s$ решений имеет ранг не больше $n - r < s$, и по теореме о ранге (теорема [-@thm:lec08:rank]) её $s$ столбцов зависимы. Для ФСР с добавленным решением $s = n - r + 1$.
:::

Тем самым число $n - r$ в определении ФСР [-@def:lec09:fsr] — наибольшее возможное число независимых решений. В модуле 3 это прочитается так: решения $Ax = 0$ образуют линейное пространство, ФСР — его базис, а $n - r$ — размерность.

::: {.remark #rem:lec10:homogeneous-corner tag="корнер-кейс"}
При $r = n$ ФСР нет, и теорема [-@thm:lec10:homogeneous] не применима; общее решение — единственный столбец $x = 0$ (замечание [-@rem:lec09:fsr-corner]). При $A = O$ ($r = 0$) общее решение — $c_1 e_1 + \dots + c_n e_n$, то есть любой столбец: каждый столбец $(c_1, \dots, c_n)^T$ раскладывается по столбцам $e_j$ матрицы $E$.
:::

## Структура общего решения неоднородной СЛАУ {#sec:lec10:nonhomogeneous}

Для неоднородной системы $Ax = b$ линейные комбинации решений, вообще говоря, не решения: сумма двух решений решает $Ax = 2b$ (замечание [-@rem:lec08:nonhomogeneous-trap]). Но по свойствам 2 и 3 (утверждение [-@prop:lec08:solution-properties]) все её решения получаются из одного сдвигом на решения однородной системы (рис. [-@fig:lec08:shift]). Теперь, когда решения однородной системы описаны теоремой [-@thm:lec10:homogeneous], это даёт явную формулу.

::: {.theorem #thm:lec10:nonhomogeneous title="о структуре общего решения неоднородной СЛАУ"}
Пусть система $Ax = b$ совместна и $\tilde x$ — какое-нибудь её решение (*частное решение*; в лекциях 8–9 оно обозначалось $x^0$). Если $r = \operatorname{Rg} A < n$ и $\Phi_1, \dots, \Phi_k$, $k = n - r$, — ФСР соответствующей однородной системы $Ax = 0$, то любое решение $Ax = b$ представляется в виде
$$x = \tilde x + c_1 \Phi_1 + \dots + c_k \Phi_k, \qquad c_1, \dots, c_k \in \R,$$ {#eq:lec10:general-nonhomogeneous}
и при любых $c_1, \dots, c_k$ такой столбец — решение $Ax = b$. Если $r = n$, то решение единственно: $x = \tilde x$.
:::

::: proof
Пусть $x$ — решение $Ax = b$. По свойству 3 (утверждение [-@prop:lec08:solution-properties]) разность $x - \tilde x$ — решение $Ax = 0$. При $r < n$ по теореме [-@thm:lec10:homogeneous] $x - \tilde x = c_1 \Phi_1 + \dots + c_k \Phi_k$, откуда [-@eq:lec10:general-nonhomogeneous]. При $r = n$ у $Ax = 0$ только нулевое решение (замечание [-@rem:lec09:fsr-corner]), и $x = \tilde x$.

Обратно, $c_1 \Phi_1 + \dots + c_k \Phi_k$ — решение $Ax = 0$ (свойство 1), и по свойству 2 сумма $\tilde x$ и этого столбца — решение $Ax = b$.
:::

Формулу [-@eq:lec10:general-nonhomogeneous] запоминают словами: *общее решение неоднородной системы = частное решение неоднородной + общее решение однородной*, $x_{\text{о.н.}} = x_{\text{ч.н.}} + x_{\text{о.о.}}$. Геометрически множество решений однородной системы — «плоскость» размерности $k$ в $n$-мерном пространстве, проходящая через ноль (ноль — всегда решение). В трёхмерном пространстве, в аналитической геометрии, это будет прямая или плоскость через начало координат. Множество решений неоднородной системы — та же плоскость, параллельно сдвинутая на вектор $\tilde x$: она проходит через конец $\tilde x$ и, вообще говоря, уже не через ноль (рис. [-@fig:lec08:shift]). Такое сдвинутое множество называют *линейным многообразием*. Тот же принцип встретится в матанализе: так устроены решения линейных дифференциальных уравнений.

::: {.definition #def:lec10:general-nonhomogeneous title="общее решение неоднородной СЛАУ"}
Запись [-@eq:lec10:general-nonhomogeneous], где $\tilde x$ — частное решение $Ax = b$, $\Phi_1, \dots, \Phi_k$ — ФСР системы $Ax = 0$, а $c_1, \dots, c_k$ — произвольные числа, называется *общим решением* неоднородной системы (в векторной форме).
:::

### Как решать СЛАУ целиком {#sec:lec10:method}

Одного прохода метода Гаусса по расширенной матрице хватает на всё: и на проверку совместности, и на частное решение, и на ФСР. Сначала весь путь на примере.

::: {.example #ex:lec10:nonhomogeneous}
Найдём общее решение системы с той же матрицей, что в примерах [-@ex:lec09:kc] и [-@ex:lec09:fsr], но с другой правой частью:
$$\begin{cases} x_1 + 2x_2 + 3x_3 - x_4 = -1, \\ -x_1 - 3x_2 + 5x_4 = 8, \\ 2x_1 + 3x_2 + 9x_3 + 2x_4 = 5. \end{cases}$$

Те же преобразования, что в примере [-@ex:lec09:kc]: $\rw{II} + \rw{I}$, $\rw{III} - 2 \cdot \rw{I}$, затем $\rw{III} - \rw{II}$; теперь последняя строка обнуляется целиком:
$$\begin{pmatrix} 1 & 2 & 3 & -1 & | & -1 \\ -1 & -3 & 0 & 5 & | & 8 \\ 2 & 3 & 9 & 2 & | & 5 \end{pmatrix} \to \begin{pmatrix} 1 & 2 & 3 & -1 & | & -1 \\ 0 & -1 & 3 & 4 & | & 7 \\ 0 & -1 & 3 & 4 & | & 7 \end{pmatrix} \to \begin{pmatrix} 1 & 2 & 3 & -1 & | & -1 \\ 0 & -1 & 3 & 4 & | & 7 \\ 0 & 0 & 0 & 0 & | & 0 \end{pmatrix}.$$
$\operatorname{Rg} A = \operatorname{Rg} (A \mid b) = 2$ — система совместна (теорема [-@thm:lec08:kronecker-capelli]). Доведём до канонического вида: $\rw{II} \cdot (-1)$, затем $\rw{I} - 2 \cdot \rw{II}$:
$$\begin{pmatrix} 1 & 0 & 9 & 7 & | & 13 \\ 0 & 1 & -3 & -4 & | & -7 \\ 0 & 0 & 0 & 0 & | & 0 \end{pmatrix}, \qquad \begin{cases} x_1 = 13 - 9x_3 - 7x_4, \\ x_2 = -7 + 3x_3 + 4x_4. \end{cases}$$
Главные переменные — $x_1, x_2$ (в их столбцах ведущие единицы, минор $M^{12}_{12} = 1$ базисный), свободные — $x_3, x_4$; справа записана приведённая система. *Частное решение:* свободным даём нули, $\tilde x = (13, -7, 0, 0)^T$. Проверка: $13 - 14 = -1$, $-13 + 21 = 8$, $26 - 21 = 5$. *ФСР однородной системы:* те же формулы без свободных членов $13$ и $-7$, то есть канонический вид без последнего столбца; это нормальная ФСР из примера [-@ex:lec09:fsr]. По теореме [-@thm:lec10:nonhomogeneous] получаем ответ.

*Ответ:* $x = (13, -7, 0, 0)^T + c_1 (-9, 3, 1, 0)^T + c_2 (-7, 4, 0, 1)^T$, $c_1, c_2 \in \R$.
:::

Алгоритм в общем виде:

1. Привести $(A \mid b)$ к ступенчатому виду строковыми преобразованиями и сравнить ранги. Если есть строка $\begin{pmatrix} 0 & \dots & 0 & | & c \end{pmatrix}$ с $c \ne 0$, система несовместна, и дальше идти незачем.
2. Довести до канонического вида, назвать главные переменные (столбцы ведущих единиц) и свободные; выразить главные через свободные.
3. Частное решение $\tilde x$: все свободные равны $0$, главные равны свободным членам — числам из последнего столбца канонического вида.
4. ФСР однородной системы: те же формулы без свободных членов; свободным даём наборы «одна единица, остальные нули» (как в лекции 9).
5. Записать ответ в виде [-@eq:lec10:general-nonhomogeneous] и проверить подстановкой $\tilde x$ и каждое $\Phi_j$: первое должно давать $b$, остальные — нули.

Если матрица квадратная и невырожденная, ФСР нет, и решение единственно: быстрее правило Крамера или $x = A^{-1} b$ (утверждение [-@prop:lec06:unique-solution]). Алгоритм выше нужен, когда решений бесконечно много или когда матрица прямоугольная.

::: {.remark #rem:lec10:c0-trap tag="подводный камень"}
Перед частным решением коэффициент не ставится. Запись $x = c_0 \tilde x + c_1 \Phi_1 + \dots + c_k \Phi_k$ выглядит симметричнее, но при $c_0 \ne 1$ даёт не решения: $A(c_0 \tilde x + \dots) = c_0 b \ne b$. В примере [-@ex:lec10:nonhomogeneous] при $c_0 = 2$, $c_1 = c_2 = 0$ получится $(26, -14, 0, 0)^T$, и первое уравнение даёт $26 - 28 = -2 \ne -1$. Частное решение сдвигает множество решений однородной системы, а не растягивается вместе с ним (свойство 2, а не свойство 1).
:::

::: {.remark #rem:lec10:sign-trap tag="подводный камень"}
Компоненты ФСР берутся из канонического вида *с противоположным знаком*: строка $\begin{pmatrix} 1 & 0 & 9 & 7 & | & 13 \end{pmatrix}$ означает $x_1 + 9x_3 + 7x_4 = 13$, то есть $x_1 = 13 - 9x_3 - 7x_4$. Если переписать в $\Phi_1$ число $9$ вместо $-9$, получится столбец $(9, -3, 1, 0)^T$, который не решение: $9 - 6 + 3 = 6 \ne 0$. А свободные члены (последний столбец) входят в $\tilde x$ *со своим* знаком. Проверка подстановкой ловит обе ошибки.
:::

::: {.remark #rem:lec10:compare-answers}
Частное решение можно взять любое, и ФСР — любую, поэтому верные ответы бывают разного вида. Например, $\tilde x + \Phi_1 = (4, -4, 1, 0)^T$ — тоже частное решение системы из примера [-@ex:lec10:nonhomogeneous] ($4 - 8 + 3 = -1$, $-4 + 12 = 8$, $8 - 12 + 9 = 5$), и запись $(4, -4, 1, 0)^T + c_1 \Phi_1 + c_2 \Phi_2$ задаёт то же множество. Чтобы сверить свой ответ $\tilde x + \sum c_j \Phi_j$ с чужим $\tilde y + \sum c_j \Psi_j$, достаточно проверить три вещи: $\tilde y$ — решение $Ax = b$; каждое $\Psi_j$ — решение $Ax = 0$; число $\Psi_j$ равно $n - r$ и они независимы. Тогда по теоремам [-@thm:lec10:homogeneous] и [-@thm:lec10:nonhomogeneous] множества совпадают.
:::

## Комплексные числа {#sec:lec10:complex}

### Зачем расширять $\R$

Вещественных чисел не хватает уже для многочленов: у $x^2 + 1$ вещественных корней нет, ведь $x^2 \ge 0$; так же у любого квадратного трёхчлена с отрицательным дискриминантом. Комплексные числа расширяют $\R$ так, что у любого многочлена степени $n$ появляются ровно $n$ корней (это будет в лекциях 11–12). Поэтому их удобно применять как промежуточный инструмент и в задачах, где ответ вещественный: в физике (колебания, повороты и растяжения), в обработке сигналов и анализе данных (преобразование Фурье, спектральный анализ временных рядов).

Вещественное число — точка прямой. Новое число будем задавать парой вещественных — точкой плоскости. Складывать пары естественно покомпонентно, как векторы. Умножение устроено хитрее, и именно оно отличает комплексные числа от векторов: векторы плоскости друг на друга умножать не умеют.

### Определение и алгебраическая форма

::: {.definition #def:lec10:complex title="комплексные числа"}
*Комплексными числами* называются упорядоченные пары $z = (x, y)$ вещественных чисел, для которых равенство, сложение и умножение заданы так:
$$\begin{aligned} (x_1, y_1) = (x_2, y_2) \;&\Leftrightarrow\; x_1 = x_2 \text{ и } y_1 = y_2, \\ (x_1, y_1) + (x_2, y_2) &= (x_1 + x_2, \; y_1 + y_2), \\ (x_1, y_1) \cdot (x_2, y_2) &= (x_1 x_2 - y_1 y_2, \; x_1 y_2 + x_2 y_1). \end{aligned}$$ {#eq:lec10:operations}
Множество комплексных чисел обозначается $\mathbb{C}$. Пару $(x, 0)$ отождествляют с вещественным числом $x$. *Разность* $z_1 - z_2 := (x_1 - x_2, \; y_1 - y_2)$ — единственное $w$, для которого $z_2 + w = z_1$.
:::

Сокращённо комплексные числа иногда пишут «КЧ»; обычно комплексное число обозначают одной буквой, $z = (x, y)$. Формула умножения выглядит странно, но она подобрана ровно под нашу цель: $(0, 1) \cdot (0, 1) = (0 \cdot 0 - 1 \cdot 1, \; 0 \cdot 1 + 0 \cdot 1) = (-1, 0)$. Ниже увидим, что это число $-1$. Формула симметрична относительно перестановки сомножителей, поэтому $z_1 z_2 = z_2 z_1$. Сложение покомпонентное, и его свойства (коммутативность, ассоциативность, нуль $(0, 0)$, противоположное $-z = (-x, -y)$) наследуются от $\R$ покомпонентно, отсюда и разность из определения. Остальные свойства операций (ассоциативность, дистрибутивность, существование обратного) проверим в лекции 11; пока считаем строго по формулам [-@eq:lec10:operations].

*Вещественные числа внутри $\mathbb{C}$.* Пары вида $(x, 0)$ складываются и умножаются как вещественные числа:
$$(x_1, 0) + (x_2, 0) = (x_1 + x_2, 0), \qquad (x_1, 0) \cdot (x_2, 0) = (x_1 x_2 - 0, \; 0) = (x_1 x_2, 0).$$
Поэтому отождествление пары $(x, 0)$ с вещественным числом $x$ из определения [-@def:lec10:complex] согласовано с операциями, и $\R \subset \mathbb{C}$. Умножение на вещественное число умножает обе компоненты: $(a, 0) \cdot (x, y) = (ax, ay)$.

*Мнимая единица.* Обозначим $i = (0, 1)$. Тогда $i^2 = (-1, 0) = -1$, а любое комплексное число раскладывается так:
$$(x, y) = (x, 0) + (0, y) = (x, 0) \cdot (1, 0) + (y, 0) \cdot (0, 1) = x \cdot 1 + y \cdot i = x + y i.$$
Здесь $(y, 0) \cdot (0, 1) = (0 - 0, \; y + 0) = (0, y)$. Числа с нулевой второй компонентой отождествлены с вещественными, а пара $(0, 1)$ — новое число, которое так не упростить; ему и дано имя. Обычно пишут $x + iy$: множители переставлять можно.

::: {.definition #def:lec10:algebraic title="алгебраическая форма, действительная и мнимая части"}
Запись $z = x + iy$, где $x, y \in \R$, а $i = (0, 1)$ — *мнимая единица*, $i^2 = -1$, называется *алгебраической формой* комплексного числа $z = (x, y)$. Число $x = \operatorname{Re} z$ называется *действительной* (вещественной) *частью* $z$, число $y = \operatorname{Im} z$ — *мнимой частью*.
:::

Два комплексных числа равны тогда и только тогда, когда равны их действительные и мнимые части. Поэтому одно уравнение с комплексными числами — это *два* вещественных уравнения; на этом держатся почти все задачи с комплексными числами.

Число $x + iy$ изображается точкой $(x, y)$ *комплексной плоскости*: по горизонтальной оси, *вещественной*, откладывают $\operatorname{Re} z$, по вертикальной, *мнимой*, — $\operatorname{Im} z$ (рис. [-@fig:lec10:plane], слева). Вещественные числа лежат на вещественной оси, $1$ — единичный вектор на ней, а $i$ — единичный вектор на мнимой оси; отсюда и название «мнимая единица». Сложение — это сложение векторов по правилу параллелограмма (рис. [-@fig:lec10:plane], справа). Геометрический смысл умножения появится в следующей лекции вместе с тригонометрической формой.

*Умножение в алгебраической форме.* Формулу [-@eq:lec10:operations] удобно воспроизводить так: раскрыть скобки, как у многочленов от $i$, и заменить $i^2$ на $-1$:
$$(x_1 + iy_1)(x_2 + iy_2) = x_1 x_2 + i x_1 y_2 + i x_2 y_1 + i^2 y_1 y_2 = (x_1 x_2 - y_1 y_2) + i(x_1 y_2 + x_2 y_1).$$
Пока это правило запоминания: оно даёт ровно определение. Что раскрывать скобки так можно всегда, следует из свойств операций, которые проверим в следующей лекции.

::: {.example #ex:lec10:product}
Вычислим $(2 + 3i)(1 - 2i)$ и проверим, что $-1 + 2i$ — корень уравнения $z^2 + 2z + 5 = 0$.

$(2 + 3i)(1 - 2i) = 2 - 4i + 3i - 6i^2 = 8 - i$. По определению: $(2 \cdot 1 - 3 \cdot (-2), \; 2 \cdot (-2) + 1 \cdot 3) = (8, -1)$ — то же. Для корня: $(-1 + 2i)^2 = 1 - 4i + 4i^2 = -3 - 4i$, $2(-1 + 2i) = -2 + 4i$, сумма с $5$: $(-3 - 2 + 5) + i(-4 + 4) = 0$. Второй корень — $-1 - 2i$: $(-1 - 2i)^2 = -3 + 4i$, $2(-1 - 2i) = -2 - 4i$, и снова сумма с $5$ равна $0$.
:::

::: {.remark #rem:lec10:im-real tag="частое заблуждение"}
«*Мнимая часть числа $3 + 2i$ равна $2i$.*» Нет: $\operatorname{Im} z$ — *вещественное* число, коэффициент при $i$, и $\operatorname{Im}(3 + 2i) = 2$. Так же $\operatorname{Re} z$ и $\operatorname{Im} z$ — обе вещественные, и $z = \operatorname{Re} z + i \operatorname{Im} z$. У вещественного числа $\operatorname{Im} z = 0$, у числа $5i$ действительная часть $0$, мнимая $5$.
:::

::: {.remark #rem:lec10:sqrt-trap tag="подводный камень"}
Определять $i$ как «$\sqrt{-1}$» и пользоваться привычными правилами для корней опасно. Рассуждение $i^2 = \sqrt{-1} \cdot \sqrt{-1} = \sqrt{(-1)(-1)} = \sqrt{1} = 1$ выглядит как применение правила $\sqrt{a}\sqrt{b} = \sqrt{ab}$, но даёт неверный результат: $i^2 = -1$ по определению умножения. Правило $\sqrt{a}\sqrt{b} = \sqrt{ab}$ доказано только для $a, b \ge 0$. У числа $-1$ два квадратных корня, $i$ и $-i$, и запись $\sqrt{-1}$ не говорит, какой из них взят. Поэтому в выкладках пишут $i^2 = -1$, а не $i = \sqrt{-1}$.
:::

Другие операции — деление, сопряжение, модуль, а также тригонометрическую форму, в которой у умножения появится геометрический смысл, — разберём в лекции 11. Там же начнутся многочлены с комплексными коэффициентами.

# Практика

::: {.problem #prob:lec10:general-middle}
Найди общее решение системы
$$\begin{cases} x_1 + 2x_2 - x_3 + x_4 = 1, \\ 2x_1 + 4x_2 - x_3 + 3x_4 = 4, \\ x_1 + 2x_2 + x_3 + 3x_4 = 5. \end{cases}$$
:::

::: solution
$\rw{II} - 2 \cdot \rw{I}$, $\rw{III} - \rw{I}$, затем $\rw{III} - 2 \cdot \rw{II}$ и $\rw{I} + \rw{II}$:
$$\begin{pmatrix} 1 & 2 & -1 & 1 & | & 1 \\ 2 & 4 & -1 & 3 & | & 4 \\ 1 & 2 & 1 & 3 & | & 5 \end{pmatrix} \to \begin{pmatrix} 1 & 2 & -1 & 1 & | & 1 \\ 0 & 0 & 1 & 1 & | & 2 \\ 0 & 0 & 2 & 2 & | & 4 \end{pmatrix} \to \begin{pmatrix} 1 & 2 & 0 & 2 & | & 3 \\ 0 & 0 & 1 & 1 & | & 2 \\ 0 & 0 & 0 & 0 & | & 0 \end{pmatrix}.$$
Ранги $A$ и $(A \mid b)$ равны $2$, система совместна, в ФСР $4 - 2 = 2$ решения. *Ключ:* ведущие единицы в столбцах $1$ и $3$, поэтому главные — $x_1, x_3$, свободные — $x_2, x_4$, а не последние две переменные. Из канонического вида $x_1 = 3 - 2x_2 - 2x_4$, $x_3 = 2 - x_4$. Частное решение при $x_2 = x_4 = 0$: $\tilde x = (3, 0, 2, 0)^T$. ФСР: набор $x_2 = 1$, $x_4 = 0$ даёт $(-2, 1, 0, 0)^T$; набор $x_2 = 0$, $x_4 = 1$ даёт $(-2, 0, -1, 1)^T$. Проверка $\tilde x$: $3 - 2 = 1$, $6 - 2 = 4$, $3 + 2 = 5$; второго столбца ФСР: $-2 + 1 + 1 = 0$, $-4 + 1 + 3 = 0$, $-2 - 1 + 3 = 0$.

*Ответ:* $x = (3, 0, 2, 0)^T + c_1 (-2, 1, 0, 0)^T + c_2 (-2, 0, -1, 1)^T$, $c_1, c_2 \in \R$.
:::

::: {.problem #prob:lec10:param}
Исследуй систему при всех $\lambda$ и $\mu$ и найди общее решение там, где оно есть:
$$\begin{cases} x_1 + x_2 + x_3 = 1, \\ x_1 + 2x_2 + 3x_3 = 2, \\ 2x_1 + 3x_2 + \lambda x_3 = \mu. \end{cases}$$
:::

::: solution
$\rw{II} - \rw{I}$, $\rw{III} - 2 \cdot \rw{I}$, затем $\rw{III} - \rw{II}$:
$$\begin{pmatrix} 1 & 1 & 1 & | & 1 \\ 1 & 2 & 3 & | & 2 \\ 2 & 3 & \lambda & | & \mu \end{pmatrix} \to \begin{pmatrix} 1 & 1 & 1 & | & 1 \\ 0 & 1 & 2 & | & 1 \\ 0 & 1 & \lambda - 2 & | & \mu - 2 \end{pmatrix} \to \begin{pmatrix} 1 & 1 & 1 & | & 1 \\ 0 & 1 & 2 & | & 1 \\ 0 & 0 & \lambda - 4 & | & \mu - 3 \end{pmatrix}.$$
*Ключ:* параметр $\lambda$ стоит в матрице и решает, равен ли $\operatorname{Rg} A$ трём; параметр $\mu$ — только в правой части и при вырожденной матрице решает, совместна ли система.

*$\lambda \ne 4$.* $\operatorname{Rg} A = 3 = n$, решение единственно. Из последней строки $x_3 = t = \frac{\mu - 3}{\lambda - 4}$, затем $x_2 = 1 - 2t$, $x_1 = 1 - x_2 - x_3 = t$. Проверка третьего уравнения: $2t + 3 - 6t + \lambda t = 3 + (\lambda - 4) t = \mu$.

*$\lambda = 4$, $\mu \ne 3$.* Последняя строка — $0 = \mu - 3 \ne 0$: $\operatorname{Rg} A = 2 < \operatorname{Rg} (A \mid b) = 3$, несовместна.

*$\lambda = 4$, $\mu = 3$.* $\operatorname{Rg} A = \operatorname{Rg} (A \mid b) = 2$. $\rw{I} - \rw{II}$ даёт канонический вид со строками $(1, 0, -1 \mid 0)$ и $(0, 1, 2 \mid 1)$: $x_1 = x_3$, $x_2 = 1 - 2x_3$. Частное решение $(0, 1, 0)^T$, ФСР из одного столбца $(1, -2, 1)^T$ (проверка: $1 - 2 + 1 = 0$, $1 - 4 + 3 = 0$, $2 - 6 + 4 = 0$).

При $\lambda \ne 4$ решение — точка $(0, 1, 0)^T + t (1, -2, 1)^T$ прямой, заданной первыми двумя уравнениями.

*Ответ:* При $\lambda \ne 4$ решение единственно: $x = (t, \, 1 - 2t, \, t)^T$, $t = \frac{\mu - 3}{\lambda - 4}$. При $\lambda = 4$, $\mu = 3$: $x = (0, 1, 0)^T + c (1, -2, 1)^T$. При $\lambda = 4$, $\mu \ne 3$ система несовместна.
:::

::: {.problem #prob:lec10:expand}
Для системы из задачи [-@prob:lec09:fsr-middle] столбцы $\Psi_1 = (4, 1, -2, 1)^T$, $\Psi_2 = (-2, 1, 2, -1)^T$ образуют ФСР (задача [-@prob:lec09:is-fsr]). Выясни, являются ли решениями следующие столбцы, и разложи решения по $\Psi_1, \Psi_2$:

- (а) $x = (5, 2, -2, 1)^T$;
- (б) $y = (1, 1, 1, 1)^T$.
:::

::: solution
(а) Подстановка: $5 - 2 - 4 + 1 = 0$, $10 - 4 - 10 + 4 = 0$, $15 - 6 - 14 + 5 = 0$ — решение. По теореме [-@thm:lec10:homogeneous] $x = c_1 \Psi_1 + c_2 \Psi_2$. *Ключ:* в этой системе свободные переменные — $x_2$ и $x_4$, поэтому сравниваем вторую и четвёртую компоненты: $c_1 + c_2 = 2$, $c_1 - c_2 = 1$, откуда $c_1 = \frac32$, $c_2 = \frac12$. Проверка первой и третьей: $6 - 1 = 5$, $-3 + 1 = -2$.

(б) $1 - 1 + 2 + 1 = 3 \ne 0$ — не решение. Комбинации $\Psi_1, \Psi_2$ — решения (свойство 1), поэтому $y$ среди них нет: система $c_1 \Psi_1 + c_2 \Psi_2 = y$ несовместна. Если бы сравнить только вторую и четвёртую компоненты, получилось бы $c_1 = 1$, $c_2 = 0$, но тогда первая компонента $4 \ne 1$ — сравнения по свободным переменным достаточно, *только если* столбец заведомо решение.

*Ответ:*

- (а) решение, $x = \frac32 \Psi_1 + \frac12 \Psi_2$;
- (б) не решение, по ФСР не раскладывается.
:::

::: {.problem #prob:lec10:system-by-fsr}
Составь однородную систему, для которой столбцы $\Phi_1 = (1, 0, 1, 2)^T$ и $\Phi_2 = (0, 1, 1, -1)^T$ образуют ФСР.
:::

::: solution
Нужна матрица $A$ с четырьмя столбцами, для которой $A \Phi_1 = A \Phi_2 = 0$ и $n - \operatorname{Rg} A = 2$, то есть $\operatorname{Rg} A = 2$. *Ключ:* условие $A \Phi_j = 0$ означает, что каждая *строка* $a = (a_1, a_2, a_3, a_4)$ матрицы $A$ удовлетворяет $a_1 \varphi_{1j} + \dots + a_4 \varphi_{4j} = 0$, то есть строка $A$, записанная столбцом, — решение однородной системы с матрицей
$$B = \begin{pmatrix} 1 & 0 & 1 & 2 \\ 0 & 1 & 1 & -1 \end{pmatrix},$$
строки которой — $\Phi_1^T$ и $\Phi_2^T$. Матрица $B$ уже в каноническом виде: $a_1 = -a_3 - 2a_4$, $a_2 = -a_3 + a_4$. Её нормальная ФСР — $(-1, -1, 1, 0)^T$ и $(-2, 1, 0, 1)^T$; запишем их строками $A$.

Проверка: $A \Phi_1$: $-1 + 0 + 1 + 0 = 0$, $-2 + 0 + 0 + 2 = 0$; $A \Phi_2$: $0 - 1 + 1 + 0 = 0$, $0 + 1 + 0 - 1 = 0$. Строки $A$ независимы (минор $M^{34}_{12} = 1$), $\operatorname{Rg} A = 2$, и в ФСР системы $Ax = 0$ ровно $4 - 2 = 2$ решения. $\Phi_1, \Phi_2$ — решения, они независимы (не пропорциональны), значит, это ФСР. Ответ не единственный: подойдёт любая матрица, строки которой образуют ФСР системы $By = 0$, и к ней можно дописать любые их комбинации.

*Ответ:* Например, $-x_1 - x_2 + x_3 = 0$, $-2x_1 + x_2 + x_4 = 0$.
:::

::: {.problem #prob:lec10:complex-ops}
Даны комплексные числа $z_1 = (3, -2)$ и $z_2 = (-1, 4)$. Запиши их в алгебраической форме, вычисли $z_1 + 2z_2$ и $z_1 z_2$, укажи действительную и мнимую части произведения.
:::

::: solution
По определению [-@def:lec10:algebraic] $z_1 = 3 - 2i$, $z_2 = -1 + 4i$. Сумма: $z_1 + 2z_2 = (3 - 2) + (-2 + 8)i = 1 + 6i$. *Ключ:* при умножении раскрываем скобки и заменяем $i^2$ на $-1$:
$$z_1 z_2 = (3 - 2i)(-1 + 4i) = -3 + 12i + 2i - 8i^2 = 5 + 14i.$$
Проверка по определению [-@eq:lec10:operations]: $(3 \cdot (-1) - (-2) \cdot 4, \; 3 \cdot 4 + (-1) \cdot (-2)) = (5, 14)$. Мнимая часть — вещественное число $14$, без $i$ (замечание [-@rem:lec10:im-real]).

*Ответ:* $z_1 = 3 - 2i$, $z_2 = -1 + 4i$; $z_1 + 2z_2 = 1 + 6i$; $z_1 z_2 = 5 + 14i$ ($\operatorname{Re} = 5$, $\operatorname{Im} = 14$).
:::

::: {.problem #prob:lec10:sqrt}
Найди все комплексные $z$, для которых $z^2 = -3 + 4i$.
:::

::: solution
Пусть $z = x + iy$. Тогда $z^2 = (x^2 - y^2) + 2ixy$, и уравнение — система
$$\begin{cases} x^2 - y^2 = -3, \\ 2xy = 4. \end{cases}$$
*Ключ:* из второго уравнения $x \ne 0$ и $y = \frac{2}{x}$; подстановка в первое даёт биквадратное уравнение $x^2 - \frac{4}{x^2} = -3$, то есть $x^4 + 3x^2 - 4 = 0$, $(x^2 + 4)(x^2 - 1) = 0$. Так как $x$ вещественно, $x^2 = 1$: $x = 1$, $y = 2$ или $x = -1$, $y = -2$. Проверка: $(1 + 2i)^2 = 1 + 4i + 4i^2 = -3 + 4i$. Корень $x^2 = -4$ отброшен: $x$ — действительная часть, она вещественна. Ответов ровно два и они противоположны, как у квадратного корня из положительного числа.

*Ответ:* $z = \pm(1 + 2i)$.
:::

# Итоги

- Любое решение однородной системы — линейная комбинация столбцов ФСР: матрица из этого решения и столбцов ФСР имеет ранг $n - r$, потому что строки главных переменных — комбинации строк свободных с одними и теми же коэффициентами.
- Поэтому $n - r + 1$ решений однородной системы всегда зависимы: ФСР — наибольший независимый набор решений.
- Коэффициенты разложения решения по нормальной ФСР — значения свободных переменных; по произвольной ФСР их находят, сравнивая компоненты свободных переменных.
- Общее решение совместной $Ax = b$ — сдвиг общего решения $Ax = 0$ на одно частное решение $\tilde x$; частное решение берётся с коэффициентом $1$, а выбрать его можно любым, поэтому верные ответы бывают разного вида.
- Один проход метода Гаусса по $(A \mid b)$ даёт совместность, частное решение (последний столбец канонического вида) и ФСР (столбцы свободных переменных с противоположным знаком).
- Комплексные числа — пары $(x, y) = x + iy$ с умножением, при котором $i^2 = -1$; в алгебраической форме умножают, раскрывая скобки и заменяя $i^2$ на $-1$.
- Равенство комплексных чисел — два вещественных равенства, поэтому уравнения в $\mathbb{C}$ сводятся к системам для $\operatorname{Re} z$ и $\operatorname{Im} z$.
