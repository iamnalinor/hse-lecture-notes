# context/ — всё, что нужно агенту

Здесь лежат правила, по которым пишутся, проверяются и собираются конспекты лекций ПИ ФКН ВШЭ 2026/27. Один конспект = одна лекция.

**Критерий результата.** Конспект: студент, который пропустил лекцию или учит курс сам, после чтения понимает тему и решает типовые задачи семинара по ней. Сайт: этим удобно пользоваться с телефона и ноутбука. Пайплайн: все конспекты семестра собираются одной командой, проходят ревью сабагентом по чеклисту и попадают на сайт без ручной правки.

Источник правил — ТЗ из дока «Формат конспекта: рекомендации для агента» (вкладка «Рекомендации» — `recommendations.md`, остальное разнесено по файлам ниже). При расхождении верно то, что проверяет код (`scripts/lint.py`, `scripts/build.py`, `filters/notes.lua`), затем `recommendations.md` → остальное; найденное расхождение исправь в тексте.

## С чего начать

Любая задача: сначала `process.md` (план → проверка перед «готово» → ревью отдельным агентом). Потом — строка своей задачи:

| Задача | Читать (по порядку) |
| --- | --- |
| Написать конспект | `workflow.md` (он ведет по остальным: `courses/<course>.md` → `conventions.md` → `recommendations.md` → `style/writing-ru.md` → `markup.md` → `prompts/generate.md`) |
| Отревьюить конспект | `prompts/facts.md` → `prompts/review.md` → `recommendations.md` (чеклист) → `style/writing-ru.md` → `conventions.md` → `markup.md` → `courses/<course>.md` |
| Перевести прогноз в конспект по лекции | `prompts/normalize.md` → `workflow.md` |
| Добавить лекцию в план, поменять дату | `workflow.md` §1 и §10 |
| Обновить теорию курса | `prompts/theory.md` → `markup.md` §10 |
| Подготовка к КР, коллоквиуму, экзамену, квизу | `debt.md` (что не доделано) → `prompts/prep.md` → `markup.md` §11 → `courses/<course>.md` (контрольные, «Что следует из ПУД») → `program/<course>.md` |
| Отревьюить подготовку | `prompts/facts.md` → `prompts/prep-review.md` → `prompts/prep.md` |
| Читлист к КР | `prompts/cheatsheet.md` → `courses/<course>.md` → `prep/<course>/krN.md` |
| Страница «План учебной дисциплины» | `prompts/program.md` → `markup.md` §12 |
| Отревьюить любую другую страницу | `prompts/facts.md` → промпт этой страницы → `style/writing-ru.md` |
| Работать над сайтом и ревьюить его | `web/README.md` → `site.md` → `style/design.md` |

## Файлы

**Правила, общие для всего**

| Файл | Что внутри |
| --- | --- |
| `debt.md` | долги: что решено, но отложено (подготовка к КР по новой схеме, мелочи дизайна) |
| `process.md` | как работать: план, доказательство перед «готово», тест вперед, отладка, ревью сабагентом, сабагенты и лимиты |
| `style/writing-ru.md` | Т1–Т27: русский текст без признаков нейросети, с примерами из матана |
| `style/design.md` | Д1–Д74: дизайн и удобство сайта, сценарии «удобство на деле» |
| `prompts/facts.md` | фактчекинг утверждений о курсе; страница — справочник, а не пересказ |

**Конспекты**

| Файл | Что внутри |
| --- | --- |
| `recommendations.md` | цель и скелет конспекта, Р1–Р32 с примерами, запреты, чеклист |
| `conventions.md` | обозначения: общие и по курсам |
| `markup.md` | синтаксис: front matter, разделы, блоки, метки, ссылки, формулы, TikZ, теория курса (§10), подготовка (§11), программа (§12) |
| `workflow.md` | путь конспекта от строки в плане до коммита; расписание, модули и нумерация лекций (§10) |
| `prompts/generate.md`, `prompts/review.md`, `prompts/normalize.md` | написать, отревьюить, привести прогноз к лекции |

**Курсы и источники**

| Файл | Что внутри |
| --- | --- |
| `courses/<course>.md` | всё по курсу: план с датами и `week_id`, состав лекций, источники, темп, контрольные, «Что следует из ПУД» |
| `sources.md` | все источники со ссылками и как их достать |

**Другие страницы и сайт**

| Файл | Что внутри |
| --- | --- |
| `prompts/theory.md`, `prompts/prep.md`, `prompts/prep-review.md`, `prompts/cheatsheet.md`, `prompts/program.md` | теория курса, подготовка к КР и коллоквиуму, её ревью, читлист, ПУД |
| `site.md` | требования к сайту и формат данных сборки |
| `../chat-suggestions/README.md` | стартовые вопросы чата: по 6 на страницу в YAML, сборка в JSON |

## Инструменты (из корня репозитория)

```bash
./scripts/setup.sh                       # TinyTeX + пакеты + uv sync
export PATH="$HOME/.TinyTeX/bin/x86_64-linux:$PATH"
./scripts/fetch_sources.sh               # публичные источники → sources/
uv run scripts/lint.py [файлы]           # проверка схемы и запретов
uv run scripts/build.py [--only glob]    # PDF + HTML + индекс в build/
uv run scripts/render_pages.py <pdf>     # страницы PDF → PNG для просмотра
uv run pytest -q                         # тесты пайплайна
./scripts/fetch_skills.sh                # оригиналы скиллов из process.md и style/ → .cache/skills/
```
