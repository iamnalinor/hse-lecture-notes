# context/ — всё, что нужно агенту

Здесь лежат правила, по которым пишутся, проверяются и собираются конспекты лекций ПИ ФКН ВШЭ 2026/27. Один конспект = одна лекция.

**Критерий результата.** Конспект: студент, не бывший на лекции, после чтения понимает тему так же, как после лекции, и решает типовые задачи семинара по ней. Пайплайн: все конспекты семестра собираются одной командой, проходят ревью сабагентом по чеклисту и попадают на сайт без ручной правки.

Источник правил — ТЗ из дока «Формат конспекта: рекомендации для агента» (вкладка «Рекомендации» — `recommendations.md`, остальное разнесено по файлам ниже). При расхождении верно то, что проверяет код (`scripts/lint.py`, `scripts/build.py`, `filters/notes.lua`), затем `recommendations.md` → остальное; найденное расхождение исправь в тексте.

## Что читать

| Задача | Читать (по порядку) |
| --- | --- |
| Написать конспект | `workflow.md` (он ведёт по остальным: `courses/<course>.md` → `conventions.md` → `recommendations.md` → `markup.md` → `prompts/generate.md`) |
| Отревьюить конспект | `prompts/review.md` → `conventions.md` → `recommendations.md` (чеклист) → `markup.md` → `courses/<course>.md` |
| Обновить теорию курса | `prompts/theory.md` → `markup.md` §10 |
| Перевести прогноз в конспект по лекции | `prompts/normalize.md` → `workflow.md` |
| Добавить новую лекцию в план | `workflow.md` §1 → `schedule.md` |
| Подготовка к КР (страница `prep/<course>/krN.md`) | `prompts/prep.md` → `markup.md` §11 → `courses/<course>.md` (раздел про контрольные) |
| Отревьюить подготовку к КР | `prompts/prep-review.md` → `prompts/prep.md` |
| Читлист (шпаргалка) к КР | `prompts/cheatsheet.md` → `courses/<course>.md` (правила контрольной) → `prep/<course>/krN.md` |
| Работать над сайтом | `web/README.md` → `site.md` |

## Файлы

| Файл | Что внутри |
| --- | --- |
| `recommendations.md` | вкладка «Рекомендации»: цель и скелет конспекта, Р1–Р32 с примерами «как надо / как не надо», запреты, чеклист перед выдачей |
| `markup.md` | синтаксис: front matter, разделы, блоки, метки, ссылки, формулы, TikZ, глоссарий, теория курса |
| `workflow.md` | полный путь добавления конспекта: от строки в плане до коммита; нормировка прогноза |
| `conventions.md` | обозначения и соглашения: общие и по курсам |
| `schedule.md` | модули, дни лекций, правила нумерации и дат |
| `sources.md` | все источники со ссылками и способ их достать |
| `site.md` | требования к сайту (`web/`) и формат данных, которые отдаёт сборка |
| `design-brief.md` | исторический бриф для дизайнера первого макета сайта; актуальное — `site.md` и `web/README.md` |
| `prompts/generate.md` | как писать конспект (шаги, требования к тексту, отчёт) |
| `prompts/review.md` | как ревьюить: три слоя, приоритеты, формат замечаний |
| `prompts/theory.md` | как вести теорию курса; расширения на потом |
| `prompts/normalize.md` | как переводить прогноз в конспект по лекции |
| `prompts/prep.md` | как писать подготовку к КР: темы, методы, прототипы, пробный вариант |
| `prompts/prep-review.md` | как ревьюить подготовку к КР |
| `prompts/cheatsheet.md` | как делать читлист к КР: когда можно, варианты печати, вёрстка, содержание, ревью |
| `courses/<course>.md` | всё по курсу: план семестра с датами и `week_id`, подробный состав лекций, источники, реальные темы 2026, группировка по агентам, статус конспектов, контрольные |
| `courses/calculus-grading.md` | матанализ: элементы контроля и формула оценки из программы дисциплины 2026/27 (что входит в коллоквиум и письменный экзамен, репетиции, веса) |

## Инструменты (из корня репозитория)

```bash
./scripts/setup.sh                       # TinyTeX + пакеты + uv sync
export PATH="$HOME/.TinyTeX/bin/x86_64-linux:$PATH"
./scripts/fetch_sources.sh               # публичные источники → sources/
uv run scripts/lint.py [файлы]           # проверка схемы и запретов
uv run scripts/build.py [--only glob]    # PDF + HTML + индекс в build/
uv run scripts/render_pages.py <pdf>     # страницы PDF → PNG для просмотра
uv run pytest -q                         # тесты пайплайна
```
