**Тема:** формальная логика, метод математической индукции, неравенство Бернулли (н1).

**Порядок изложения (по доске 2026):**

### Лекция 2 — 11.09 — `02_sep11_binomial_sequences` (basis: lecture)

**Тема:** бином Ньютона и комбинаторика; последовательности (н2).

**Порядок изложения (по доске):**
1. Повтор неравенства Бернулли и пример: существует ли $n$ с $1{,}001^n > 2026$ ($n > 2\,025\,000$). Пример*: существует ли $n > 1$ с $1{,}001^n > n$ (а $> n^2$, $n^3$, $2026n^3$)? «Попытка через Бернулли» не проходит ($1 + 0{,}001n > n$ неверно) — мотивация бинома.
2. Формулировка бинома: $(a+b)^n = \sum_{k=0}^{n} C_n^k a^k b^{n-k}$.
3. «Комбинаторный ликбез»: перестановка (упорядоченное множество из $n$ элементов), $P_n = n!$; размещение (упорядоченное подмножество из $k$ элементов $n$-элементного множества, $0 \le k \le n$), $A_n^k = n(n-1)\dots(n-k+1) = \frac{n!}{(n-k)!}$; сочетание (неупорядоченное подмножество), одно сочетание ↔ $k!$ размещений, $C_n^k = \frac{A_n^k}{k!} = \frac{n!}{k!(n-k)!}$; $0! = 1$, $C_n^0 = 1$, $C_n^1 = n$. Примеры на $X = \{1, 2, 3\}$.
4. Доказательство бинома **комбинаторно**: раскрытие $n$ скобок, пример $(a+b)^3$ с выписанными 8 мономами; коэффициент при $a^{n-k} b^k$ = число мономов до приведения подобных = $C_n^k$.
5. Ответ на пример* (вероятно, через член бинома $C_n^2 \cdot 0{,}001^2$; на кадрах решения нет — восстановить).
6. Последовательность: набор вещественных чисел, пронумерованных натуральными индексами; обозначения $a_1, a_2, \dots$ или $(a_n)_{n \in \N}$.
7. Способы задания: формулой ($a_n = 2n^2 - n - 3$), рекуррентно (Фибоначчи), словесно ($n$-я цифра числа $\pi$); примеры: простые числа, постоянная. В таблице есть «способы визуализации» (точки на прямой, график $n \mapsto a_n$) — на кадрах не видно, дать рисунки.
8. Монотонность: «монотонно возрастающая» $\forall n\ a_n < a_{n+1}$, «монотонно убывающая» $a_n > a_{n+1}$ (строгие). Неубывающая/невозрастающая на кадрах лекции 2 не видны, но «неубывающая» используется в теореме Вейерштрасса (лекция 5) — ввести здесь.
9. Ограниченность сверху: $\exists C \in \R\ \forall n \in \N\ a_n < C$; замечание: кванторы нельзя переставить ($\forall n \exists C$ верно для любой последовательности). Ограниченность снизу и «ограниченность = сверху и снизу» лектор, судя по Сем2 №5, давал (в конце лекции 2 или в лекции 3); эквивалентность с $\exists C > 0\ \forall n\ |a_n| < C$ — задача семинара (Сем2 №5), в конспекте — утверждение с доказательством.

### Лекция 5 — 02.10 — `05_oct02_supremum_weierstrass` (basis: lecture)

**Тема:** аксиома непрерывности, точные грани, теорема Вейерштрасса, число $e$, подпоследовательности (н5 + часть н6). В тот же день записана «Консультация 02.10» (не просматривалась; вероятно, к Quiz2/КР1).

**Порядок изложения (по доске):**
1. Аксиома непрерывности: $A, B \subset \R$, $A, B \ne \varnothing$, $\forall a \in A\ \forall b \in B\ a \le b$ ⇒ $\exists c \in \R\ \forall a, b\colon a \le c \le b$. Пример: $A = \{x > 0 \mid x^2 < 2\}$, $B = \{x > 0 \mid x^2 > 2\}$ — для $\Q$ неверно. Рисунок.
2. Опр. $A \subset \R$ ограничено сверху: $\exists C \in \R\ \forall a \in A\ a \le C$ (нестрогое!). Верхняя грань: $c \in \R$, $\forall a \in A\ c \ge a$. Точная верхняя грань (супремум) — наименьшая из верхних граней, $\sup(A)$. Примеры: $\sup[0;1] = 1 = \sup(0;1)$, $\sup(0, \sqrt2) = \sqrt2$. Замечание: если $\exists \max A$, то $\sup A = \max A$.
3. Теорема о существовании точной грани: $\varnothing \ne A \subset \R$ ограничено сверху ⇒ $\exists \sup(A)$; доказательство через аксиому непрерывности с $B$ = множество верхних граней.
4. Аналогично: нижняя грань, инфимум $\inf(A)$.
5. Характеризация супремума через $\varepsilon$ ($\forall \varepsilon > 0\ \exists a \in A\colon a > \sup A - \varepsilon$) — явно на кадрах нет, но используется в доказательстве Вейерштрасса и в Сем5 №3 / ДЗ №2 — оформить как утверждение.
6. Теорема Вейерштрасса: $(a_n)$ неубывающая и ограниченная (сверху) ⇒ сходится; доказательство: $a = \sup\{a_1, a_2, \dots\}$, от противного $a - \varepsilon_0$ — верхняя грань. Вариант для невозрастающей — аналогично.
7. Число $e$: теорема — $a_n = (1 + \frac1n)^n$ сходится. (1) возрастание: $\frac{a_{n+1}}{a_n} = \frac{n+2}{n+1}\left(1 - \frac{1}{(n+1)^2}\right)^n \ge \frac{n+2}{n+1}\left(1 - \frac{n}{(n+1)^2}\right) = \frac{n^3+3n^2+3n+2}{n^3+3n^2+3n+1} > 1$ (Бернулли); (2) ограниченность: бином, $a_n \le 2 + \frac1{2!} + \dots + \frac1{n!} \le 2 + \sum \frac{1}{(k-1)k} < 3$. Обозначение $\lim (1 + \frac1n)^n = e$.
8. Подпоследовательность: $(b_k)_{k \in \N}$, $b_k = a_{n_k}$, $n_1 < n_2 < n_3 < \dots$; примеры и не-пример ($a_4, a_2, a_8, a_6$). Свойство $n_k \ge k$.
9. Утв.: $a_n \to a \Rightarrow a_{n_k} \to a$.

**Из семинара в теорию:** нахождение $\sup$/$\inf$ множеств с обоснованием (две части: верхняя грань + «нельзя меньше») — Сем5 №3, ДЗ №2, самост. №2; рекуррентные последовательности: монотонность и ограниченность по индукции → Вейерштрасс → предельный переход в рекуррентном соотношении (КР1 №7; листок 2026 к этой теме не опубликован — 2023/24 `Сем_05` №4, ДЗ №3, самост. №4, `Сем_06` №6); пределы вида $(1 + \frac{k}{n})^n \to e^k$, $(1 - \frac1n)^n \to e^{-1}$ и неопределённость $1^\infty$ через подпоследовательности/арифметику (тема семинара н6 «Число e»; 2023/24 `Сем_07` №1–3; КР1 №5c).
