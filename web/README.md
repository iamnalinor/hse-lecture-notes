# web — сайт конспектов

React 19 + Vite + TypeScript, Tailwind v4, React Router, TanStack Query, KaTeX. Менеджер пакетов и рантайм скриптов — только Bun (`.bun-version`).
Сайт читает данные из `build/site-data` (см. `context/site.md`).

```bash
cd web
bun install
bun data:pull        # site-data и PDF из последнего успешного «Build notes» на main → public/ (нужен gh)
bun dev              # http://localhost:5173
bun run lint         # format → eslint → tsc → knip → jscpd → dependency-cruiser; единственная точка входа, чинит сам
bun run test         # vitest + testing-library (не `bun test`: это встроенный раннер Bun)
bun run build        # dist/ (+ 404.html и копии оболочки по страницам для GitHub Pages, sw.js и offline-manifest.json)
```

## Устройство

```
src/domain    чистая логика и zod-схемы данных сборки (без React, fetch, DOM)
src/api       загрузка JSON/HTML, запросы TanStack Query
src/shared    UI-кит, ридер конспекта (HTML-фрагмент → React: блоки, ссылки с превью, KaTeX, спойлеры)
src/features  страницы: home (плитка подготовки — нейтральная, акцент по `isHighlighted` из `domain/preps.ts`), course (кнопки в два ряда: лекция и документы курса; активные подготовки; под таблицей лекций — «Источники» из `domain/sources.ts`), lecture, theory, program («План учебной дисциплины», `/<course>/program`; таблицы — карточками на телефоне), prep (подготовка к КР и коллоквиуму, `/<course>/kr1`, `/<course>/colloq1`; в шапке — PDF читлиста, если он есть; генератор билетов или вариантов, если есть банк), glossary (друг друга не импортируют)
src/app       роутер, оболочка (скелетоны при переходах)
sw/           service worker: отдельный бандл, из src берёт только domain/offline.ts
```

Границы слоёв проверяет dependency-cruiser. Правила линтера — `eslint.config.ts` (строгий набор из iamnalinor/pace-dev: typed strict, sonarjs, unicorn, perfectionist, лимиты размера функций, kebab-case файлов, без default export и `index.ts`); отключённое отключено с причиной.

Генератор билетов (`src/features/prep/ticket-*.tsx`, логика выбора — `src/domain/tickets.ts`): на странице подготовки с `bank: true` в `courses.json` карточка с подписью `about` и кнопкой «Сгенерировать» встаёт в конец раздела `sec:<prep>:generator` — через `slots` (`CourseDocument` → `FragmentView` → обработчик `section` в `transform.tsx`: React-содержимое в конец раздела по его id). Банк (`data/<course>/<prep>/bank.json`) грузится при открытии страницы; ответ на вопрос (`Reveal` с `lazy`, у кнопки — `aria-label` «Ответ на вопрос N») — только по «Показать ответ»: блоки по `refs` вырезаются из `fragment.html` своих документов (`extractBlock` в `shared/reader/extract-preview.ts`, без `id`, у задачи — вместе с ответом и решением, у утверждения в пунктах с `proofs` — со следующим за ним `div.nb-proof`) и рисуются тем же `FragmentView`. Вопрос вида выбирается с вероятностью, пропорциональной `weight`. На странице КР (`krN`) набор называется вариантом: «Генератор вариантов», «Вариант 2: …». Новый набор объявляется скринридеру (`aria-live`). Набор живёт в состоянии компонента: ни адреса, ни таймера.

Фрагмент конспекта разбирает `html-react-parser`: `div.nb` → `Block`, `a.ref` → `RefLink` (якорь по номеру + превью блока при наведении, по тапу на телефоне), `span.math` → KaTeX, `nb-proof` → сворачиваемое доказательство, `nb-answer`/`nb-solution` → спойлеры внутри карточки задачи.

Поиск (`src/shared/search/`, логика — `src/domain/search.ts`): модальный `<dialog>` по ⌘K / Ctrl+K или «/». Номер («4.3») ищется точно по `index.json`, слова — по `data/search.json` (весь текст без ответов к задачам и без копий блоков в теории, ~1,6 МБ; грузится при первом открытии, дальше из кэша service worker; «Скачать все» его не сохраняет): совпадение с началом слова (TeX формул не ищется), у слов длиннее 4 букв отбрасываются 2 последние буквы («миноры» → «мино»), слово в заголовке весит больше, чем в тексте. Код диалога — отдельный чанк, подгружается через 2 с после открытия страницы. Горячие клавиши проверяются по `event.code`: работают и в русской раскладке.

Google Analytics (GA4) вставляет плагин в `vite.config.ts` только в `vite build`: в `bun dev` и тестах счётчика нет. Переходы внутри SPA GA4 считает сам («Enhanced measurement → page changes based on browser history events»).

Шрифт — HSE Sans (`src/styles/fonts/`, 400/600/700/900; курсива у шрифта нет, браузер наклоняет сам), формулы — KaTeX.

## Офлайн

`scripts/build-sw.ts` после `vite build` считает хэш каждого файла в `dist/` и пишет `offline-manifest.json`: оболочка (`index.html`, JS, CSS, woff2) и общие данные (`courses.json`, `index.json`, `katex-macros.json`) — `precache`, каждая лекция, теория, программа курса, подготовка и глоссарий курса — документ из нескольких файлов (вид — `kind`: `notes`, `theory`, `program`, `prep`, `glossary`; id курсовых документов — `COURSE_DOCS` в `src/domain/course-docs.ts`). В `sw.js` вшита только версия манифеста, поэтому проверка обновлений раз в минуту стоит ~3 КБ.

- install: скачивает изменившиеся файлы оболочки в промежуточный кэш, старая версия пока продолжает работать;
- activate: удаляет из кэша файлы, чей хэш не совпал с новым манифестом (конспект перезагрузится, только если правда поменялся), переносит новые;
- fetch: навигация → `index.html` из кэша; известные файлы — из кэша, иначе из сети с сохранением; открытая лекция сохраняется целиком, вместе с рисунками ниже по странице; PDF — только сеть.

Футер показывает «Офлайн: N из M конспектов» (считаются только копии с актуальным хэшем, счётчик растёт по мере скачивания) и кнопку «Скачать все». Новая версия — плашка сверху (`src/shared/offline/`).

**Фоновое скачивание на Wi-Fi.** Если соединение точно не лимитное, сайт сам скачивает все документы, как «Скачать все», но в фоне; в футере — «Сохраняем остальные в фоне…».

- Правило (`src/domain/connection.ts`): `navigator.connection` есть, `saveData` выключен, `type` — `wifi` или `ethernet`, `effectiveType` не `2g`/`slow-2g`. Атрибута `metered` в браузерах нет (убран из спеки), а `type` Chromium отдаёт только на Android и ChromeOS: в десктопном Chrome (тип неизвестен: ноутбук может сидеть на раздаче с телефона), в Firefox и Safari (API нет), на `cellular`, `bluetooth`, `wimax`, `mixed`, `other`, `unknown` фоновой загрузки нет — остаётся кнопка. Отказаться — включить в браузере экономию трафика (`saveData`).
- Не мешает чтению (`src/shared/offline/background-download.ts`): старт через 5 с после `load` в idle-период; файлы по одному, каждый — в idle-период, когда у страницы нет своих запросов (`isFetching` TanStack Query); `fetch` с `priority: "low"` и заголовком `x-offline-background`, по которому воркер сам идёт в сеть с низким приоритетом и не докачивает остальные файлы документа параллельно. Файлы сохраняет тот же воркер, в тот же кэш.
- Соединение стало `cellular` или включили `saveData` (событие `change`) — загрузка сразу прерывается и продолжится, если снова будет Wi-Fi. Во скрытой вкладке продолжается. Закончилась (или упала) — в этой вкладке для этой версии больше не запускается; нажатие «Скачать все» забирает работу на себя (4 потока, с прогрессом). В `bun dev` воркер не регистрируется; проверять — `bun run build` и раздать `dist/` статикой.

## Деплой

`.github/workflows/pages.yml`: после успешного «Build notes» на `main` берёт его артефакты `site-data` и `pdf`, собирает сайт с `BASE_PATH=/<repo>/` и публикует на GitHub Pages. Проверки фронта — `.github/workflows/web.yml`.

### Прямые ссылки на Pages

У Pages нет SPA-фолбэка: неизвестный путь отдаёт `404.html` со статусом 404. Поэтому `scripts/spa-fallback.ts` после сборки:

- копирует оболочку (`index.html`) в `404.html`: любой путь запускает роутер;
- кладёт копию оболочки в `dist/<course>/`, `<course>/theory/`, `<course>/program/`, `<course>/glossary/`, `<course>/krN/` и `<course>/<week_id>/index.html` (только для существующих документов) с заголовком, description и og-тегами этой страницы. Такая ссылка отдаётся со статусом 200 и со своим `<title>`, превью ссылок и поисковики видят настоящую страницу.

Оговорка: копии лежат как `каталог/index.html`, поэтому адрес без слэша (`/algebra/theory`) Pages сначала редиректит на `/algebra/theory/` (301), потом отдаёт страницу. Вариант `<route>.html` без редиректа не проверялся: неясно, как Pages ведёт себя, когда рядом лежат `algebra.html` и каталог `algebra/`, поэтому оставлен каталог. Ссылки внутри сайта идут через роутер и перезагрузки не вызывают.

Копии оболочки не входят в `offline-manifest.json` и service worker их не кэширует: любая навигация в его области отдаётся из закэшированного `index.html`. Смоук-тест `pages.yml` проверяет, что `/algebra/theory/` отдаёт копию с `<title>Алгебра: теория`, а `/calculus/program/` — с `<title>План учебной дисциплины: математический анализ`, а не `404.html`.
