# Соглашения курса

- Машина Тьюринга: пустая ячейка — $\Lambda$, начальное состояние — $q_0$, состояние останова — $q_s$, сдвиги головки — $L$, $R$, $H$ (на месте). В начале головка стоит на самом левом символе входного слова (на пустом слове — на любой пустой ячейке), результат — слово на ленте от самой левой до самой правой непустой ячейки в $q_s$.
- Стандарт C в курсе — C99; отличия C11 и C23 оговариваются отдельно.

# 1. Алгоритм и машина Тьюринга

::: {.definition ref="def:lec01:algorithm"}
**Алгоритм (интуитивно)** — точное предписание, задающее вычислительный процесс от варьируемых начальных данных к результату; свойства: конечность (результативность), определенность (детерминированность), простота и понятность, массовость.
:::

::: {.definition ref="def:lec01:alphabet"}
**Алфавит** $A_p = \{a_1, \dots, a_p\}$ — конечное непустое множество символов; слово длины $m$ — последовательность $m$ символов; $\varepsilon$ — пустое слово; $A_p^* = \bigcup_{m \ge 0} A_p^m$; $|w|$ — длина слова, $|\varepsilon| = 0$.
:::

::: {.proposition ref="prop:lec01:encoding"}
Любой алфавит $A$ можно посимвольно закодировать словами в любом алфавите $B$ с однозначным раскодированием; если $|B| = 1$ и $|A| \ge 2$ — только с добавлением служебного символа «конец кода символа» (без него коды $a_1a_2$ и $a_2a_1$ совпадают). *Идея:* при $|B| = q \ge 2$ — номер символа в системе по основанию $q$, коды одной длины — наименьшего $k \ge 1$ с $q^k \ge |A|$; при $q = 1$ — унарный код с разделителем.
:::

::: {.corollary ref="cor:lec01:one-alphabet"}
Можно ограничиться одним алфавитом, обычно $A_1$ или $A_2 = \{0, 1\}$.
:::

::: {.definition ref="def:lec01:tm"}
**Машина Тьюринга**: входной алфавит $A$, вспомогательный $A'$, рабочий $S = A \cup A' \ni \Lambda$, состояния $Q = \{q_0, \dots, q_n\}$ с начальным $q_0$ и состоянием останова $q_s$, программа — команды $\langle q, s\rangle \to \langle q', s', d\rangle$, $d \in \{L, R, H\}$, для $q \ne q_s$.
:::

::: {.definition ref="def:lec01:configuration"}
**Конфигурация** — $\langle n, F, q\rangle$: номер рабочей ячейки $n \in \Z$, запись на ленте $F\colon \Z \to S$, состояние $q$; позиция — $\langle n, q\rangle$.
:::

::: {.definition ref="def:lec01:computable"}
**Вычислимость по Тьюрингу**: МТ $T$ вычисляет частичную функцию $F\colon A^* \to A^*$, если на $w$ из области определения останавливается с результатом $F(w)$, а вне её не останавливается; такая $F$ вычислима по Тьюрингу.
:::

**Тезис Тьюринга–Чёрча**: любая интуитивно вычислимая функция вычислима машиной Тьюринга. Это гипотеза, а не теорема: она связывает строгое понятие с интуитивным.

# 2. Универсальная МТ, проблема останова, фон Нейман

::: {.definition ref="def:lec02:normal-tm"}
**Нормальная МТ**: в $q_0$ головка на пустой ячейке сразу за входным словом, в $q_s$ — на пустой ячейке сразу за результатом.
:::

::: {.proposition ref="prop:lec02:half-tape" status="на лекции — только идея"}
Любую МТ можно промоделировать МТ с лентой, ограниченной слева: ячейка $n$ хранится в ячейке $2n$ при $n \ge 0$ и $2|n| - 1$ при $n < 0$. *Идея:* перегнуть ленту по ячейке $0$; половину, на которой стоит головка, помнить в состоянии.
:::

::: {.definition ref="def:lec02:simulation"}
**Моделирование**: $M$ моделирует $M'$, если $M$ останавливается (выходит за край ленты) за конечное число шагов тогда и только тогда, когда $M'$, и в последовательности конфигураций $M$ есть подпоследовательность, по которой шаг за шагом восстанавливаются лента, рабочая ячейка и состояние $M'$.
:::

::: {.definition ref="def:lec02:utm"}
**Универсальная МТ** для алфавита $A$ — машина $U$, на которой можно промоделировать любую МТ над $A$. Строится явно: в начале ленты $U$ (ограниченной слева) — закодированная таблица моделируемой машины, дальше — её лента с данными; $U$ по состоянию и символу находит команду и выполняет её.
:::

::: {.definition ref="def:lec02:decidable"}
**Описание МТ** — код её таблицы словом во входном алфавите машины-решателя. Задача о МТ алгоритмически разрешима, если есть машина, которая на любом входе останавливается и пишет $1$ («да») или $0$ («нет»).
:::

::: {.theorem ref="thm:lec02:halting"}
Проблема останова (по МТ $T$ и слову $w$ определить, остановится ли $T$ на $w$) алгоритмически неразрешима. *Идея:* из решателя $D$ строим $E$ («$D$ на паре $T$, описание $T$») и $E^*$ («после $E$: при $1$ зациклиться, при $0$ остановиться»); $E^*$ на собственном описании останавливается тогда и только тогда, когда не останавливается.
:::

::: {.definition ref="def:lec02:self-applicable"}
**Самоприменимая** МТ: МТ самоприменима, если останавливается на собственном описании; проблема самоприменимости — по МТ определить, самоприменима ли она.
:::

::: {.theorem ref="thm:lec02:self-applicability"}
Проблема самоприменимости алгоритмически неразрешима. *Идея:* то же диагональное рассуждение, машина-решатель играет роль $E$.
:::

::: {.definition ref="def:lec02:von-neumann"}
**Архитектура фон Неймана** — устройство компьютера, в котором программа и данные хранятся в одной общей памяти, а процессор читает из неё команды и выполняет их одну за другой; процессор, память и внешние устройства связаны шиной.
:::

# 3. Язык C: первая программа, память, типы

::: {.definition ref="def:lec03:declaration"}
**Объявление функции** — имя, число и типы параметров и тип результата; этого достаточно, чтобы скомпилировать вызов. **Определение функции** — объявление вместе с телом. Программа на C состоит из объявлений переменных и функций и определений функций.
:::

::: {.definition ref="def:lec03:format-string"}
**Форматная строка** — первый аргумент `printf`: обычные символы печатаются как есть; управляющая последовательность начинается с `\` (`\n`, `\t`, `\"`, `\\`); спецификатор формата начинается с `%` и подставляет следующий аргумент (`%d` — `int`, `%%` — знак процента).
:::

::: {.definition ref="def:lec03:byte"}
**Байт** — наименьший участок памяти со своим адресом; в нём не меньше $8$ бит (`CHAR_BIT`). Размеры типов — целое число байтов.
:::

::: {.definition ref="def:lec03:storage-class"}
**Классы памяти**: статическая — всё время работы программы (глобальные переменные, текст программы), выделяется до `main`; автоматическая — на время работы функции (локальные переменные), выделяет и освобождает компилятор; регистровая — регистры процессора, `register` только подсказка; динамическая — выделяется и освобождается программой явно, когда объем или время жизни неизвестны при компиляции.
:::

::: {.definition ref="def:lec03:int-types"}
**Целые типы** `char`, `short`, `int`, `long`, `long long` (знаковые и `unsigned`): `sizeof(char) == 1`; `short` и `int` не меньше $16$ бит, `long` — $32$, `long long` — $64$; каждый следующий вмещает все значения предыдущего. Границы значений — `limits.h`, типы фиксированной ширины `int32_t`, `uint8_t` и др. — `stdint.h`.
:::

::: {.definition ref="def:lec03:behavior"}
**Категории поведения**: определенное — результат задан стандартом; определяемое реализацией — реализация выбирает и документирует (размер `int`, знаковость `char`); неуточненное — реализация выбирает любой допустимый вариант без документирования (порядок вычисления аргументов функции); неопределенное — стандарт ничего не требует (переполнение знакового целого).
:::

::: {.definition ref="def:lec03:endianness"}
**Порядок байтов**: little-endian — по младшему адресу младший байт числа; big-endian — по младшему адресу старший байт.
:::

::: {.definition ref="def:lec03:network-order"}
**Сетевой порядок байтов** — big-endian, в нём числа записываются в сетевые пакеты.
:::

::: {.definition ref="def:lec03:twos-complement"}
**Дополнительный код** из $n$ бит: $x \ge 0$ записывается двоичной записью $x$, $x < 0$ — записью $2^n - |x|$; диапазон $[-2^{n-1}, 2^{n-1} - 1]$, старший бит знаковый. С C23 обязателен для знаковых целых.
:::

::: {.proposition ref="prop:lec03:twos-add"}
Пусть $[x] \in [0, 2^n - 1]$ — дополнительный код числа $x$. Если $a$, $b$, $a + b$ в диапазоне, то $[a + b] = ([a] + [b]) \bmod 2^n$; если $x$ и $-x$ в диапазоне, то $[-x]$ — инверсия битов $[x]$ плюс $1$ (по модулю $2^n$). *Идея:* $[x]$ — остаток от деления $x$ на $2^n$; инверсия $y$ равна $2^n - 1 - y$.
:::

::: {.definition ref="def:lec03:reserved-names"}
**Зарезервированные идентификаторы** — начинающиеся с `_` и заглавной буквы или с `__`; их использует реализация для новых возможностей, программа их не объявляет.
:::

::: {.definition ref="def:lec03:bool"}
**Логический тип** `_Bool` (C99) — беззнаковый целый тип со значениями $0$ и $1$, любое ненулевое значение при записи становится $1$. Имена `bool`, `true`, `false` — из `stdbool.h` (C99–C17), в C23 — ключевые слова.
:::

# 4. Переменные, литералы, операции над целыми

::: {.definition ref="def:lec04:variable"}
**Переменная** — именованный объект программы: тип, имя и значение. Объявление `тип имя1, имя2;` может задавать класс памяти и начальное значение.
:::

::: {.definition ref="def:lec04:scope"}
**Область действия** имени — часть текста, где им можно пользоваться: у локальной переменной — от объявления до конца блока, у параметра — тело функции, у глобальной — от объявления до конца файла. Область действия и класс памяти независимы: глобальная переменная только статическая, локальная по умолчанию автоматическая, а со `static` — статическая (живет всю программу, помнит значение между вызовами). Внутренняя область действия затеняет внешнюю.
:::

::: {.definition ref="def:lec04:initialization"}
**Начальное значение без инициализатора**: статические переменные обнуляются, значение автоматических не определено, и читать его до записи нельзя.
:::

::: {.definition ref="def:lec04:literal"}
**Литерал** (константа) — запись значения в тексте программы. Целые: десятичные, восьмеричные (`0`), шестнадцатеричные (`0x`), двоичные (`0b`, C23); суффиксы `u`, `l`, `ll`; без суффикса тип — первый из списка, вмещающий значение (у десятичных — `int`, `long`, `long long`, у остальных — с беззнаковыми вариантами между ними). Символьная константа `'A'` имеет тип `int` и значение кода символа; вещественная без суффикса — `double`.
:::

::: {.definition ref="def:lec04:expression"}
**Операция** — знак вычисления над операндами (арность, приоритет, ассоциативность); **выражение** — переменная, константа, вызов функции или операция над выражениями, у него есть значение, тип и, возможно, побочный эффект; **оператор** (statement) — выполняемая конструкция без значения: выражение с `;`, блок, `if`, `while`, `return`.
:::

::: {.definition ref="def:lec04:division"}
**Деление нацело** — `a / b` есть частное с округлением к нулю (C99), остаток задается тождеством $(a / b) \cdot b + a \,\%\, b = a$ и имеет знак делимого. Деление и остаток на ноль, а также `INT_MIN / -1` и `INT_MIN % -1` — неопределенное поведение.
:::

::: {.definition ref="def:lec04:overflow"}
**Переполнение** — беззнаковая арифметика идет по модулю $2^N$ и не переполняется; результат знаковой операции вне диапазона типа — неопределенное поведение.
:::

::: {.definition ref="def:lec04:short-circuit"}
**Ленивое вычисление** — `&&` и `||` вычисляют операнды слева направо, правый — только если результат не ясен по левому. Результат отношений, сравнений и логических операций — `0` или `1` типа `int`.
:::

::: {.definition ref="def:lec04:conditional"}
**Условная операция** `c ? x : y` — вычисляет `c`, затем только одну ветку: `x`, если `c` не ноль, иначе `y`; после условия точка следования; ветки приводятся к общему типу.
:::

::: {.definition ref="def:lec04:lvalue"}
**lvalue** — выражение, указывающее на объект в памяти (может стоять слева от `=`); **rvalue** — выражение, только дающее значение. Присваивание — выражение со значением левой части после присваивания.
:::

::: {.definition ref="def:lec04:incdec"}
**Инкремент и декремент** — `++x`, `--x` дают новое значение, `x++`, `x--` — старое.
:::

::: {.definition ref="def:lec04:sequence-point"}
**Точка следования** — момент, когда побочные эффекты предыдущих вычислений закончены, а последующих не начаты: после первого операнда `&&`, `||`, `,` и условия `?:`, в конце полного выражения, перед вызовом функции. Между соседними точками следования переменную можно изменить не более одного раза и читать старое значение только ради нового, иначе — неопределенное поведение.
:::

::: {.definition ref="def:lec04:shifts"}
**Сдвиги** `E1 << E2`, `E1 >> E2` — тип результата — продвинутый тип `E1`; `E2 < 0` или не меньше ширины типа — неопределенное поведение; `<<` знакового с отрицательным `E1` или переполнением — неопределенное поведение; `>>` отрицательного знакового — определяется реализацией (GCC: арифметический сдвиг).
:::

::: {.definition ref="def:lec04:cast"}
**Явное приведение** `(тип) выражение` — одноместная операция, преобразует значение к типу; связывает сильнее `*`, `/`, `+`.
:::

::: {.definition ref="def:lec04:promotion"}
**Целочисленное продвижение** — значения типов ранга ниже `int` перед операцией преобразуются в `int`, если он вмещает все их значения, иначе в `unsigned int`.
:::

::: {.definition ref="def:lec04:usual-conversions"}
**Обычные арифметические преобразования** — по порядку: если один операнд `long double` — второй к нему, иначе `double`, иначе `float`; иначе продвижение обоих; одинаковая знаковость — к большему рангу; ранг беззнакового не меньше — к беззнаковому; знаковый вмещает все значения беззнакового — к знаковому; иначе оба к беззнаковой версии знакового.
:::

::: {.definition ref="def:lec04:sizeof"}
**`sizeof`** — операция: размер типа или типа выражения в байтах, результат типа `size_t` (беззнаковый, `%zu`); операнд не вычисляется.
:::

::: {.definition ref="def:lec04:robust"}
**Корректная программа** на любой допустимый ввод выдает требуемый вывод; **удобная** — корректная программа, которая на недопустимый ввод выдает понятное сообщение об ошибке. `scanf` получает адреса переменных и возвращает число прочитанных значений (`EOF`, если ввод кончился до первого), его проверяют.
:::

# 5. Операторы: ветвления и циклы

::: {.definition ref="def:lec05:statement"}
**Выражение-оператор** `выражение;` вычисляет выражение ради побочного эффекта; **пустой оператор** `;` ничего не делает; **составной оператор** (блок) `{ … }` объединяет объявления и операторы в один оператор.
:::

::: {.definition ref="def:lec05:if"}
**Условный оператор** `if (e) S1 else S2` выполняет `S1`, если `e` не ноль, иначе `S2` (ветка `else` необязательна). `else` относится к ближайшему `if` без `else`.
:::

::: {.definition ref="def:lec05:switch"}
**Оператор выбора** `switch (e) { case c: … default: … }` — `e` целого типа, после `case` разные целые константные выражения; управление переходит на метку с равным значением, иначе на `default`, и выполнение идет подряд до `break` или конца тела (проваливание).
:::

::: {.definition ref="def:lec05:while"}
**Цикл с предусловием** `while (e) S` повторяет `S`, пока `e` не ноль, и может не выполнить его ни разу; **цикл с постусловием** `do S while (e);` проверяет `e` после тела и выполняет его хотя бы раз.
:::

::: {.definition ref="def:lec05:for"}
**Цикл** `for (e1; e2; e3) S` — один раз `e1`, затем пока `e2` не ноль: `S`, потом `e3`. Пропущенное `e2` истинно; объявление в `e1` видно только в цикле.
:::

::: {.definition ref="def:lec05:jumps"}
**Операторы перехода**: `break` выходит из ближайшего цикла или `switch`; `continue` заканчивает текущий проход ближайшего цикла (в `for` — переход к `e3`); `goto метка` переходит к метке, видной во всей функции.
:::
